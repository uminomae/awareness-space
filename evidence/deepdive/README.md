# evidence/deepdive/ -- 深掘り探索

このディレクトリは、`evidence` 本体の主張を壊さずに、追加調査・再検証・横断洞察を行うための分離領域である。

## 役割

- Level2 以降の深掘り探索結果を運用する
- 論証の強化、反証シナリオ、追加調査の実験ログを整理する
- 深掘り後の反映要件を明示して `PROJECT.md` / `evidence/README.md` と整合させる

## 何を置くか

深掘り実行ログ、比較メモ、追加調査結果、洞察ノートを置く。

## 現状

この `awareness-space` 構成では、まだプレースホルダ段階であり空ディレクトリ。

## 補足

- `evidence/evidence-D*.md` の Revise とは別に扱う
- 深掘り成果は将来的に `knowledge/` や `transform/` への反映指示と併記して進める
