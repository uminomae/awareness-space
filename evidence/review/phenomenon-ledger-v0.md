# phenomenon ledger v0

`awareness-space` の現象先行再調査に向けた初期台帳。

ここでは既存ラベルを使わず、
「意識経験の中で何が起きているか」を中立 ID で保持する。
`Withhold` のような既存名は source 内の語としてのみ参照し、
この台帳の entry 名には使わない。

## 0. 読み方

- `P-xxx` は概念名ではなく、現象断片の ID
- 本版は初回抽出であり、確定分類ではない
- 特に `すぐ反応しない` 系は 1 つにまとめず、複数 entry に分けて記録する

## 1. 初期クラスター一覧

|---|---|---|
| P-001 | 身体から逃れられない常時モニタリング | 注意、解釈、評価 |

## 2. エントリ

### P-001 身体状態が常時モニタされ続ける

- 現象記述:
  身体内部の状態は遮断できず、常時の足場として経験に供給される。
- 文脈:
  覚醒時だけでなく、ぼんやりしている時や睡眠に近い状態でも持続する。
- 成立条件:
  - 身体状態表象が継続している
  - 体内信号が経験の背景として残る
- 不成立条件:
  - 身体そのものが経験から切り離せる、という想定
- 近縁現象:
  - 外受容入力
  - 注意の焦点化
- 反例 / 境界:
  - 身体を感じていない主観報告があっても、背景層としては停止していない可能性
- source:
  - `knowledge/domains/four-layers/part-2-interoception.md`
  - `evidence/review/neurophenomenology-design.md`

### P-002 差異が「違和感 / 欠け」として前景化する

- 現象記述:
  予期と入力の差の一部が、単なる差ではなく「足りない」「変だ」として立ち上がる。
- 文脈:
  味の違い、会話の違和感、夢の追跡感など、多様な局面で起こる。
- 成立条件:
  - 予期や見立てが先行している
  - 差が前意識的吸収を通り抜ける
  - 差に目立ちや重要度がある
- 不成立条件:
  - 差が自動更新で吸収される
  - そもそも見立てが弱く、欠けとして感じられない
- 近縁現象:
  - 三人称的な誤差記述
  - 価値づけ後の情動
- 反例 / 境界:
  - 全ての差異が一人称的な「欠け」になるわけではない
- source:
  - `knowledge/domains/four-layers/part-3-prediction-error.md`
  - `evidence/review/neurophenomenology-design.md`

### P-003 差異が即時反応へ短絡する

- 現象記述:
  差異や脅威読みが強く立ち、再検討より先に闘争・逃走・即断へ向かう。
- 文脈:
  怒鳴る、すぐ決める、今すぐ対処しないと危ないと感じる場面。
- 成立条件:
  - 差異が高緊急度で読まれる
  - 身体余裕や文脈余裕が低い
  - 代替案を保つコストが高い
- 不成立条件:
  - 結論を急がずに問いを保持できる
  - 安全感があり、即応しなくてももつ
- 近縁現象:
  - 迅速な適応的判断
  - 凍結
- 反例 / 境界:
  - 行動が速いこと自体は P-003 ではない。再評価の余地が残るなら別
- source:
  - `knowledge/domains/four-layers/part-5-withhold.md`
  - `knowledge/concepts/CN-003_boundary-casebook.md`

### P-004 行動は止まるが、問いは開かれない

- 現象記述:
  反応は止まっているように見えるが、更新や再評価は進まず、同じ説明や固着が続く。
- 文脈:
  反復説明、我慢、凍結に近い停止、資料だけ増えて差分が出ない状況。
- 成立条件:
  - 即応は止まっている
  - しかし新しい問いや差分が生まれない
  - 既知の説明に戻り続ける
- 不成立条件:
  - 保持中に問いが一文化される
  - 差分が追跡される
- 近縁現象:
  - 凍結
  - 見かけ上の我慢
  - P-005 の問い保持
- 反例 / 境界:
  - 外見上静かでも、内部で問いが保持されているなら P-004 ではない
- source:
  - `knowledge/concepts/CN-003_boundary-casebook.md`
  - `knowledge/domains/withhold/ja/report.md`

### P-005 問いを保持したまま閉じない

- 現象記述:
  行動準備や差異をすぐ解消せず、問いとして残しつつ再評価可能な状態を保つ。
- 文脈:
  「いま保持している問い」を一文で言える、別案をまだ置ける、結論を急がない。
- 成立条件:
  - 差異が消えていない
  - それでも即応せずに保持できる
  - 再評価の余地が残る
- 不成立条件:
  - 単なる停止で更新がない
  - すぐ結論で閉じる
- 近縁現象:
  - 反応抑制
  - 迷い
  - P-004 の固着
- 反例 / 境界:
  - 「待っている」ようでも、問いがなく単に回避しているだけなら別
- source:
  - `knowledge/domains/withhold/ja/report.md`
  - `knowledge/domains/four-layers/part-5-withhold.md`
  - `knowledge/concepts/CN-003_boundary-casebook.md`

### P-006 内在化された関係が保留可能性を支える

- 現象記述:
  物理的に誰かが今そこにいなくても、内在化された関係や安全基地があることで、差異を持ちこたえられる。
- 文脈:
  過去の養育者、恩師、支援者、心の中の関係が支えになる場面。
- 成立条件:
  - 安全基地や内的作業モデルが形成されている
  - 関係が外在ではなく内在化されている
- 不成立条件:
  - 関係が全く足場にならない
  - 支えが物理的同席に完全依存する
- 近縁現象:
  - 現在の支援関係
  - 単なる所属感
- 反例 / 境界:
  - 関係があるだけでは足りず、その質が不安定なら保留可能性を支えない
- source:
  - `knowledge/concepts/CN-001_internalized-relationship.md`
  - `evidence/review/developmental-psychology-design.md`
  - `knowledge/domains/withhold/ja/report.md`

### P-007 外部化が保持と差分追跡の足場になる

- 現象記述:
  メモ、図、共有物、ノートなどが、問いを保ち続ける外部スタックとして機能する。
- 文脈:
  1文の問いを書き残す、次回差分だけを見る、共有物に問いを保持する場面。
- 成立条件:
  - 問いが外部化されている
  - 次回以降も差分を追える
  - 結論の代替でなく保留の支援になっている
- 不成立条件:
  - 書類だけ増えて更新がない
  - 外部化が単なる記録で、問い保持に使われない
- 近縁現象:
  - 情報整理
  - 作業管理
- 反例 / 境界:
  - 共有物があるだけで保持になるわけではない。差分と再評価が必要
- source:
  - `knowledge/concepts/CN-003_boundary-casebook.md`
  - `knowledge/concepts/CN-004_collective-withhold.md`
  - `knowledge/domains/four-layers/part-5-withhold.md`

### P-008 支援者依存でのみ成立する保留

- 現象記述:
  対話中や支援直後には落ち着くが、不在になるとすぐ即応や崩れへ戻る。
- 文脈:
  面談直後は保てるが、数時間後に「今すぐ決めないと」と戻る場面。
- 成立条件:
  - 外的支えがある間だけ保留が成立する
  - 自力継続や外部化継続が弱い
- 不成立条件:
  - 支援者不在でも問いを持続できる
- 近縁現象:
  - P-006 の内在化された関係
  - P-005 の自立的保持
- 反例 / 境界:
  - 他者支援があること自体は問題ではない。支援不在時の急落が境界
- source:
  - `knowledge/concepts/CN-003_boundary-casebook.md`
  - `knowledge/domains/four-layers/part-5-withhold.md`

### P-009 場が保留コストを分散する

- 現象記述:
  個人の努力だけでなく、対話・制度・共有物が連動することで、即断せずに問いを場として保持できる。
- 文脈:
  「いったん保留」と言える会議、止める権限が守られる制度、共有された問いが残る場面。
- 成立条件:
  - 対話で保留が言語化できる
  - 制度として止める権限や再帰問いがある
  - 外部化された問いと差分が残る
- 不成立条件:
  - 保留が個人依存
  - 制度が形だけで更新がない
- 近縁現象:
  - 個人の自己抑制
  - 組織の単なる会議運用
- 反例 / 境界:
  - 手順が多いだけで更新がない場合は P-009 ではなく、P-004 の集団版に近い
- source:
  - `knowledge/concepts/CN-004_collective-withhold.md`
  - `knowledge/concepts/CN-003_boundary-casebook.md`

## 3. 初回の分離結果

今回の初回抽出で、少なくとも次は分けて扱う必要がある。

1. 差異の前景化そのもの
2. 差異の即時短絡
3. 停止しているが更新しない状態
4. 問いとして保持できる状態
5. 関係が支える保持
6. 支援依存の保持
7. 外部化による保持
8. 集団・制度による保持

この時点で、
`すぐ反応しない` を 1 語で束ねるのは粗すぎる。
