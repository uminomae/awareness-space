# report priority

`#54` の判断メモ。

この文書は、
生存-信頼軸、4層モデル、Containment のうち、
どの report を次に厚くするかを決めるための優先順位メモである。

## 1. 判断基準

今回の優先順位は、次の 3 点で比較する。

1. **成熟度**  
   既にどれだけ source と report が揃っているか

2. **依存関係**  
   他の report の理解を支える土台になるか

3. **未解決の大きさ**  
   中心語や成立条件がまだ大きく揺れていないか

## 2. 各 report の現状

### 2-1. 4層モデル

強み:

- Layer 0 と Layer 1 の source reading が進んだ
- M1 の part 群と直接接続している
- 生存-信頼軸と Containment を 1 つの流れで束ねる枠組みとして使える

弱み:

- Layer 2 / Layer 3 の精密化はまだ必要
- 各層の観測可能性は未整理

評価:

- **成熟度: 高**
- **依存関係の中心性: 高**
- **未解決の大きさ: 中**

### 2-2. 生存-信頼軸

強み:

- repo の起点仮説である
- 既に report と起点メモがある
- 多くの論点が最終的にここへ戻ってくる

弱み:

- 信頼軸の中心語が未確定
- 愛着 / 信頼 / 所属 / 間主観性の境界がまだ揺れている
- 発達心理学側の読解をまだ十分に通していない

評価:

- **成熟度: 中**
- **依存関係の中心性: 高**
- **未解決の大きさ: 高**

### 2-3. Containment

強み:

- report は既にあり、独自性も強い
- 4層モデルと発達心理学の接続点として重要

弱み:

- Layer 3 単独機能か循環全体かが未決
- 成立条件が身体、関係安全性、認知枠組みにまたがっている
- 信頼 / 関係安全性 / 修復可能性の整理がまだ十分でない

評価:

- **成熟度: 中**
- **依存関係の中心性: 中**
- **未解決の大きさ: 高**

## 3. 優先順位

### 1位: 4層モデル

理由:

- 現在もっとも source が揃っている
- Layer 0 / Layer 1 読解をすでに反映できる
- 生存-信頼軸と Containment の両方を包む枠組みとして機能する

### 2位: 生存-信頼軸

理由:

- repo の起点仮説なので重要度は高い
- ただし 信頼軸の中心語がまだ揺れている
- 発達心理学側の信頼 / 間主観性整理を反映してから厚くしたほうがよい

### 3位: Containment

理由:

- 独自性は高いが、依存している前提がまだ多い
- 愛着、安全基地、信頼、関係安全性の整理を受けてから厚くしたほうが無理がない

## 4. 実行順

1. 4層モデル report を先に厚くする
2. 生存-信頼軸 report を次に厚くする
3. Containment report はその後に厚くする
