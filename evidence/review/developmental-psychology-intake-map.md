# developmental psychology intake map

`awareness-space` における発達心理学 intake の正本。

この文書は、
発達心理学系 source を一般的な発達段階論としてではなく、
**信頼軸、関係安全性、関係調整をどう記述するか**
という観点で束ねるための map である。

## 1. この map の役割

- 愛着、安全基地、内的作業モデル、間主観性、修復可能性を intake 順に束ねる
- 発達心理学が意識モデルに返せる論点と、まだ返せない論点を分ける
- 信頼軸の中心語候補を整理し、固定しない語も明示する
- survey / guide / report に返す前の未確定部分を残す

## 2. intake の中心問い

発達心理学 intake では、次の 4 問いを中心に source を読む。

1. 愛着と安全基地は、信頼軸の発達基盤として何を説明できるか
2. 内的作業モデルは、関係安全性をどう持続させるか
3. 信頼、所属、愛着、間主観性のうち、どれが信頼軸の中心語候補に近いか
4. 修復可能性と関係調整は、意識モデルの観測可能な条件としてどこまで使えるか

## 3. intake cluster

### 3-1. 愛着と安全基地

ここでは、
愛着、安全基地、探索可能性の関係を扱う。

主な source:

- `evidence/review/attachment-safe-base-reading.md`
- `evidence/review/developmental-psychology-design.md`
- `../kesson-driven-thinking/base/expression/core/E10.md`

この cluster が言えること:

- 安全基地は探索可能性の条件として働く
- 関係の安定は、信頼軸の発達的な基盤になる
- 安心は抽象的な気分ではなく、反復された関係経験に支えられる

まだ言えないこと:

- 信頼軸の中心語を何に固定するか
- どの程度まで他の心理学語彙へ広げるか

返し先:

- 生存-信頼軸: 信頼軸の発達基盤を補強する
- guide: 関係の安定が意識探索の前提であることを弱く示す

### 3-2. 内的作業モデル

ここでは、
外的な関係の同席ではなく、内在化された関係資源を扱う。

主な source:

- `evidence/review/attachment-safe-base-reading.md`
- `knowledge/concepts/CN-001_internalized-relationship.md`

この cluster が言えること:

- 安全基地は物理的同席に限られない
- 内的作業モデルは関係安全性の持続条件として読める
- 関係の履歴は、信頼軸の安定に影響する

まだ言えないこと:

- 内的作業モデルをどこまで意識モデルの中心語彙に入れるか
- 他の relational concept とどう切り分けるか

返し先:

- 生存-信頼軸: 信頼軸を履歴依存なものとして読む補助線
- report: 関係安全性の背景条件として限定的に返す

### 3-3. 信頼と間主観性

ここでは、
信頼を単一定義へ閉じず、間主観性との関係で位置づける。

主な source:

- `evidence/review/trust-and-intersubjectivity-reading.md`
- `knowledge/concepts/CN-005_trust-hypothesis-inventory.md`
- `knowledge/concepts/CN-006_trust-analysis-axes.md`

この cluster が言えること:

- 信頼は信頼軸の有力候補だが、そのまま信頼軸そのものではない
- 間主観性は、愛着より広い上位の表現候補として読める
- 愛着、所属、信頼、間主観性の境界はまだ固定しない方がよい

まだ言えないこと:

- 信頼軸の最終中心語
- 間主観性をどこまで reader-facing に前面化するか

返し先:

- 生存-信頼軸: 中心語候補の整理
- survey: 検討中の語彙として開示する

### 3-4. 修復可能性と関係調整

ここでは、
repair event、repair 成功率、repair 速度、関係の中での調整を扱う。

主な source:

- `evidence/review/trust-and-intersubjectivity-reading.md`
- `knowledge/concepts/CN-007_iss42-measurement-design-principles.md`

この cluster が言えること:

- 関係安全性は「壊れないこと」ではなく「修復可能であるという予期」に関わる
- 修復可能性は、信頼軸を観測可能な形へ近づける手掛かりになる
- 関係調整は個人内だけでなく、関係内プロセスとして読む必要がある

まだ言えないこと:

- 修復可能性をどの程度まで中心指標として扱うか
- 修復可能性と信頼の関係をどこまで同一視してよいか

返し先:

- survey: 現在の主要な検討点として返す
- report: 観測可能性の候補として限定的に返す

## 4. source の受け取り方

発達心理学系 source は、次の順で intake する。

1. 愛着と安全基地を基礎として読む
2. 次に内的作業モデルで持続条件を読む
3. その後で信頼と間主観性の語彙を比較する
4. 最後に修復可能性と関係調整を観測可能性の候補として置く

この順序を崩して、
抽象語から信頼軸を先に固定しない。

## 5. report / guide / survey への返し方

### report に返せるもの

- 愛着と安全基地を信頼軸の発達基盤として読む整理
- 内的作業モデルを関係安全性の背景条件として読む整理
- 修復可能性を関係安全性の観測可能な候補として置く整理

### survey に返すもの

- 発達心理学接続は整備中であること
- 愛着、安全基地、内的作業モデル、間主観性、修復可能性が主要論点であること

### guide に返すもの

- 信頼軸は単なる気分ではなく、関係経験の蓄積に支えられること
- ただし中心語はまだ固定していないこと

### まだ返さないもの

- 信頼軸の最終中心語の断定
- 間主観性の一般理論化
- 発達心理学だけで意識モデル全体を説明する書き方

## 6. 未確定論点

1. 信頼軸の中心語を、信頼 / 愛着 / 所属 / 間主観性のどれに最も寄せるか
2. 修復可能性をどの程度まで信頼軸の観測指標に使うか
3. 関係安全性を生存-信頼軸の中でどこまで独立に扱うか
