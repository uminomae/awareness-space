# neurophenomenology design

`awareness-space` における神経現象学調査の設計メモ正本。

この文書は、
神経現象学を「脳の説明」で使うのではなく、
**一人称経験をどの単位で記述するかを支える参照枠**としてどう使うかを定義する。

## 1. 目的

神経現象学調査の目的は、
意識経験の記述単位を考えるときに、

- 身体性
- 一人称経験
- 前反省的な気づき
- 予測とズレ

をどう扱うべきかを整理することである。

`awareness-space` では、神経現象学を確定理論として採用するのではなく、
生存-信頼軸と4層モデルを一人称経験に接続するための中心参照として扱う。

## 2. 主質問

### 主質問 A

意識経験を記述するとき、身体性はどこから不可欠になるのか。

特に、

- 内受容感覚
- 身体状態表象
- 身体から逃れられないこと

を扱う。

### 主質問 B

ズレや予測誤差は、どの時点で「欠け」として一人称経験に立ち上がるのか。

ここでは、

- 3人称の計算論的記述
- 1人称の現象学的記述

の区別を重視する。

### 主質問 C

前反省的な気づきや体験構造は、
4層モデルのどこに対応づけるのが妥当か。

候補:

- Layer 0 の身体足場
- Layer 1 のズレ検出
- Layer 2 以前の前景化

## 3. この調査で扱う対象

今回の神経現象学調査では、次を対象とする。

1. 内受容感覚
2. 予測-誤差ループ
3. 一人称経験と三人称記述の区別
4. 身体性と意識経験の接続
5. 前反省的な気づきの記述単位

## 4. 非対象

今回の調査では次を扱わない。

1. 脳部位の詳細な同定
2. 脳部位 = 機能 の短絡的対応づけ
3. 神経現象学だけで理論全体を証明すること
4. 新しい実験プロトコルの策定
5. Friston などの参照枠をそのまま本論に還元すること

## 5. 期待する役割

神経現象学に期待する役割は次の 3 つである。

### 5-1. 身体性の足場を与える

- Layer 0 の内受容感覚
- 身体状態表象
- AI には欠損を経験できない、という区別

を整理する。

### 5-2. ズレの一人称的立ち上がりを照らす

- 予測誤差が単なる計算ではなく
- どのように「欠け」として経験されるか

の参照枠を与える。

### 5-3. 意識経験の記述単位を精密化する

- 何を前反省的経験として扱うか
- 何を身体感覚として扱うか
- 何を評価以前の構造として扱うか

を明確にする。
