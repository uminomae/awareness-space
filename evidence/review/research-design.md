# research design

`awareness-space` の調査設計メモ正本。

この文書は、既存 source を読んだうえで、
**これから何を調査し、何をまだ調査しないか**を固定するための設計書である。

## 1. 目的

`awareness-space` の目的は、
意識をどのような単位で記述できるかを、
神経現象学と心理学を中心に再設計することである。

ここでいう再設計とは、
既存 source をそのまま確定理論として移すことではなく、
生存-信頼軸、4層モデル、M1、concept notes を素材として、
意識モデルの中核構造をどこまで記述できるかを見直すことを指す。

## 2. 主質問

### 主質問 A

意識を記述する最小単位は何か。

この問いでは、少なくとも次の候補を比較する。

- 生存-信頼軸
- 4層モデル
- 生存-信頼軸と4層モデルの組み合わせ

### 主質問 B

神経現象学は、意識経験のどの部分を記述する中心 source になりうるか。

ここでは特に、

- 一人称経験の記述単位
- 体験の構造
- 反応以前の気づき

を扱う。

### 主質問 C

心理学、特に発達心理学は、
生存-信頼軸と関係安全性のどこを検証できるか。

ここでは特に、

- 愛着
- 間主観性
- 社会的発達
- 関係の中での調整

を扱う。

## 3. 調査対象

今回の調査対象は次の 4 領域に限定する。

1. 生存-信頼軸
2. 4層モデル
3. 神経現象学
4. 発達心理学を含む心理学

補助 source として、以下を使う。

- 4層モデルの原著文書群
- concept notes
- four-modules

## 4. 非対象

今回の調査では次を扱わない。

1. D01-D30 の学問領域調査
2. 欠損駆動思考そのものの repo 外スコープ
3. 神経基盤の詳細確定
4. 実証研究の新規実施
5. 既存 source の最終理論化

## 5. 調査方法

今回の方法は、次の 3 段階に分ける。

### 5-1. source reading

既存 source を読み、

- 何が仮説か
- 何が既知として扱えるか
- 何が未解決か

を分ける。

### 5-2. 概念比較

次に、

- 生存-信頼軸が何を説明できるか
- 4層モデルが何を説明できるか
- 神経現象学と心理学がどこに接続するか

を比較する。

### 5-3. report / guide への再配置

最後に、

- 調査設計
- source map
- report

の境界を維持したまま、
どの論点を report 化し、
どの論点を exploration に残すかを決める。

## 6. 完了条件

この調査設計フェーズの完了条件は次の通り。

1. 主質問 A-C に対して、扱う source と扱わない source が決まっている
2. 神経現象学用の設計 Issue と、発達心理学用の設計 Issue に分解できる
3. 生存-信頼軸 / 4層モデル のうち、どれを中核 report として優先するか判断できる
4. guide / survey / report に何を置くかの境界が保たれている
