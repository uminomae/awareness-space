# research design baseline

`awareness-space` で新しい調査を始める前に、
これまでの調査がどういう性質のもので、何が分かっていて、何がまだ未解決かを整理するための起点メモ。

この文書は「新しい理論を足す」ためのものではなく、
既存資料をいったん棚卸しして、**次に何を調べるべきかを決めるための正本**である。

> [!NOTE]
> この文書には、`抱持` / `Withhold` を意識モデル候補として扱っていた時点の棚卸しが含まれる。現時点の `awareness-space` では `抱持` / `Withhold` を意識モデルの構成要素や検証仮説として採用しない。

## 1. この文書の役割

- 既存資料を調査種別ごとに分類する
- 現時点の既知をまとめる
- 未解決論点と非スコープを分ける
- 次に設計すべき調査の主質問を明文化する

## 3. 何が分かっているか

### 3-1. 起点仮説は 生存-信頼軸である

- `awareness-space` は 生存-信頼軸を確定理論ではなく、**探索の起点仮説**として置いている
- 生存軸は生存 / 脅威 / 安全 / 防衛
- 信頼軸は関係 / 愛着 / 所属 / 信頼 / 間主観性
- 同じズレでも 生存-信頼 の読み方で情動と行動準備の向きが変わる

### 3-2. 意識は 4層の処理連鎖として読める

- Layer 0: 内受容感覚
- Layer 1: 予測と現実のズレ検出
- Layer 2: 生存-信頼の評価
- Layer 3: 保持と再評価

少なくとも現時点の資料では、
意識を静的な内容の集積ではなく、処理の連鎖として読む枠組みが有力である。

### 3-3. 抱持 / Withhold は旧探索ラベルとして残っている

- 旧資料では `Withhold` を「止めること」ではなく「問いとして保持すること」として扱っていた
- 抑制と区別されるべき機能として読まれていた
- ただし現時点の `awareness-space` では、意識モデルの構成要素や検証仮説としては採用しない

### 3-4. M1 と concept notes は source 束として有効である

- M1 は 4層モデル、生存-信頼軸、`抱持` / `Withhold` を含む旧論点まで見渡せる基盤文章群として使える
- concept notes は境界事例、信頼、関係性、測定の補助論点を保持している
- つまり「何もないところから調査を始める」必要はなく、既に source は厚い

### 3-5. ただし多くはまだ探索的である

- 既存 report の多くは「確定理論」ではなく「有力な見立て」の段階
- 特に 生存-信頼軸、信頼、測定は仮説的な部分が多く、`抱持` / `Withhold` は現行採用の手前で止まっている
- 既知の量は多いが、**整理の仕方**がまだ固まっていない

## 4. 何がまだ未解決か

### 4-1. 主質問がまだ粗い

現状の資料は、

- 生存-信頼軸をどう置くか
- 4層モデルをどう読むか
- `抱持` / `Withhold` を旧素材としてどう扱うか

を個別には扱っているが、
`awareness-space` 全体として「最終的に何を明らかにしたいのか」がまだ粗い。

### 4-2. 神経現象学と心理学の接続の仕方が未設計

- 神経現象学を中心参照にする方針はある
- 発達心理学を含む心理学を統合する方針もある
- しかし、どの問いを神経現象学に求め、どの問いを心理学に求めるかが未分解

### 4-3. 用語がまだ揺れている

- 信頼軸を「愛」「愛着」「所属」「信頼」「間主観性」のどれで呼ぶか
- 生存軸に地位や資源まで含めるか

### 4-4. 観測・検証の仕方が未確定

- どこまでを概念モデルとして扱うか
- どこからを観測可能な指標へ落とすか
- N=1 の現象学的探索と、一般化可能な記述をどう分けるか

## 5. 非スコープ

現時点で `awareness-space` が扱わないもの:

- D01-D30 の学問領域調査
- 欠損駆動思考そのものの別 repo スコープの整理
- いきなり神経基盤の詳細確定へ進むこと
- 既存 source をそのまま確定理論として採用すること

神経現象学は、意識のどの側面を記述する中心 source なのか。

候補:

- 一人称経験の記述単位
- 体験の構造
- 反応以前の気づきの層

### 主質問 C

心理学、特に発達心理学は、生存-信頼軸や関係安全性の何を検証できるのか。

候補:

- 愛着
- 間主観性
- 関係安全性
- 社会的発達

旧資料に残る `抱持` / `Withhold` を、現行モデルへ持ち込まずにどう source として扱うか。
