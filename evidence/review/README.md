# evidence/review/ -- 調査レビューと計画

このディレクトリは、`awareness-space` の調査を設計・評価・横断分析するための作業ログ置き場である。

## 役割

- 調査設計や進捗、判断ログを保持する
- 横断レビュー、優先度調整、レビュー結果を残す
- evidence 本体に反映する前の意思決定履歴を保存する

## 何を置くか

計画メモ、レビュー結果、進捗ログ、判断保留ノートを置く。

## 現状

- `core-source-map.md`: 中核参照地図の正本
- `research-design-baseline.md`: 既存調査の棚卸しと設計起点の正本
- `research-design.md`: 調査設計メモ本体の正本
- `developmental-psychology-design.md`: 発達心理学調査の設計正本
- `neurophenomenology-design.md`: 神経現象学調査の設計正本
- `survey-5w1h-source-map.md`: survey 用の補助メモ

## 補足

- `evidence/evidence-D*.md` は主体証拠として `evidence/` 直下にある
- `knowledge/` 向けに抽象化・再解釈する前の検討材料をここで残す
