## 1. この読解の問い

Layer 1 予測-誤差ループは、
`awareness-space` において何を説明し、
どこから先をまだ説明しないのか。

## 2. 読んで分かったこと

### 2-1. Layer 1 はズレを検出し、欠損の芽を選別する

Part 3 で重要なのは、
Layer 1 が単に「誤差を計算する」層ではなく、

- 入力と見立てを照合する
- 多くのズレを前意識的に吸収する
- 一部だけを次層へ送る

という選別機能を持つ点である。

したがって Layer 1 は、
欠損そのものの全体ではなく、
**欠損が立ち上がる入口**として扱うのが妥当である。

### 2-2. 欠損は「意識化された予測誤差」ではなく一人称経験である

core-definitions の D2 は、

- 3人称: 予測誤差信号が閾値を超えて伝播する
- 1人称: 予想と現実の誤差が「欠け」として体験される

の二つの記述水準を分けている。

`awareness-space` が主語にするのは後者である。
Layer 1 を読むときも、
計算論的記述だけで完結させるのではなく、
それがどのように一人称の「足りない」に接続するかを読む必要がある。

### 2-3. Friston 系参照枠は使えるが、そのまま本論ではない

Part 3 も REVIEW-006 も、

- 予測符号化
- 自由エネルギー原理
- precision weighting

を Layer 1 の参照枠としては使っている。

しかし同時に、

- 本論の主語は 1人称の欠損経験である
- 参照枠は鏡であり代替ではない
- 誤差最小化と、誤差を問いとして拾う態度には緊張関係がある

ことも強調している。

`awareness-space` で Layer 1 を読むときは、
Friston 系を「説明し尽くす理論」として採らず、
**どこまで似ていてどこでズレるかを見る参照枠**として使うのが正しい。

### 2-4. Layer 1 は Layer 2 と Layer 3 への分岐点である

Layer 1 で選別されたズレは、

- Layer 2 へ送られて 生存-信頼 評価を受ける
- 一部は Withhold による再評価の対象になる

したがって Layer 1 は、
身体性から情動評価と保持へ移るハブである。

### 2-5. Layer 1 だけでは 信頼軸や信頼は説明しきれない

CN-005 や REVIEW-006 が示しているのは、
信頼や H08 の議論では Layer 1 だけでなく、

- L0 の身体ベースライン
- L2 のルーティング
- L3 の保持

をまとめて見ないと足りないという点である。

そのため Layer 1 を読む意義は、
信頼を直接説明することではなく、
**どの時点でズレが意識の問いになるか**を押さえることにある。

## 3. Layer 1 が説明できること

1. 入力と見立ての照合
2. ズレの検出
3. ズレの多くが前意識的に吸収されること
4. 一部のズレが欠損の芽として次層へ送られること
5. 1人称経験へ至る直前の入口

## 4. Layer 1 がまだ説明しないこと

1. そのズレが 生存軸か 信頼軸か
2. そのズレをどう保持し直すか
3. 信頼、関係安全性、間主観性の内容
4. 欠損を創造や問いに変える条件全体

これらは Layer 2 / Layer 3 以降の論点である。

## 5. awareness-space での位置づけ

`awareness-space` では Layer 1 を、

- 身体状態表象と外界入力の照合層
- 欠損の芽が選別される層
- 1人称の欠損経験へ移る境界層

として扱うのが妥当である。

逆に、
Layer 1 を単なる「予測誤差最小化装置」として還元的に読むべきではない。
