# developmental psychology design

`awareness-space` における発達心理学調査の設計メモ正本。

この文書は、
発達心理学を「発達段階の一般論」としてではなく、
**愛着、間主観性、関係安全性、社会的発達が意識モデルに何を与えるか**
という観点からどう使うかを定義する。

## 1. 目的

発達心理学調査の目的は、
意識モデルの中で 信頼軸と関係調整が成立する条件を、
発達的な観点から整理することである。

`awareness-space` では、発達心理学を用いて、

- 関係安全性がどのように形成されるか
- 愛着や内的作業モデルがどのように探索可能性を支えるか
- 社会的発達が 信頼軸の記述に何を与えるか

を考える。

## 2. 主質問

### 主質問 A

愛着は、信頼軸の発達基盤としてどこまで扱えるか。

ここでは特に、

- 安全基地
- 内的作業モデル
- 探索行動

を扱う。

### 主質問 B

間主観性や関係安全性は、生存-信頼軸の 信頼軸をどこまで記述できるか。

ここでは特に、

- 愛着
- 所属
- 信頼
- 理解されること

の境界を整理する。

### 主質問 C

社会的発達は、即時反応から再評価可能性への移行をどう支えるか。

ここでは、

- 実行機能の発達
- 養育環境
- 関係の中での調整

を扱う。

### 主質問 D

「信頼とは何か」という問いは、
発達心理学の観点からどこまで整理できるか。

## 3. この調査で扱う対象

今回の発達心理学調査では、次を対象とする。

1. 愛着
2. 安全基地
3. 内的作業モデル
4. 間主観性
5. 関係安全性
6. 社会的発達と関係調整

## 4. 非対象

今回の調査では次を扱わない。

1. 発達段階論全般の網羅
2. D23 発達心理学領域の既存調査の再利用
3. 新規の実証研究設計
4. 臨床技法そのものの整理
5. 発達心理学だけで理論全体を説明すること

## 5. 期待する役割

発達心理学に期待する役割は次の 3 つである。

### 5-1. 信頼軸の中身を具体化する

- 愛着
- 信頼
- 所属
- 間主観性

といった語のうち、どれが 信頼軸の中核に近いかを整理する。

### 5-2. 関係安全性の成立条件を発達的に支える

- 安定した関係
- 安全基地
- 内在化された関係

が、なぜ「待てる力」を育てるのかを整理する。

### 5-3. 関係調整の視点を与える

- 即時反応
- 修復可能性
- 関係の中での再評価

を、個人内だけでなく関係内のプロセスとして読む視点を与える。
