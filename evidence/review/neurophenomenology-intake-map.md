# neurophenomenology intake map

`awareness-space` における神経現象学 intake の正本。

この文書は、
既存の source reading を並べ直すためではなく、
**神経現象学系 source をどの観点で受け取り、意識モデルのどこへ返すか**
を固定するための map である。

## 1. この map の役割

- 神経現象学系 source を一人称経験の記述単位という観点で束ねる
- Layer 0 / Layer 1 / 一人称 vs 三人称の読解を、単発メモでなく intake 順へ並べ直す
- 生存-信頼軸と4層モデルへ返せる論点と、まだ返さない論点を分ける
- survey / guide / report に返す前の未確定部分を明示する

## 2. intake の中心問い

神経現象学 intake では、次の 4 問いを中心に source を読む。

1. 身体性はどこから意識経験の不可欠条件になるか
2. 差異はどの時点で一人称の違和感や欠けへ前景化するか
3. 前反省的な気づきは、どこまで記述単位として扱えるか
4. 一人称経験の記述と三人称の参照枠を、どこで書き分けるべきか

## 3. intake cluster

### 3-1. 身体性の足場

ここでは、
内受容感覚、身体状態表象、身体から逃れられないことを扱う。

主な source:

- `evidence/review/layer0-interoception-reading.md`
- `evidence/review/neurophenomenology-design.md`
- `knowledge/domains/four-layers/part-2-interoception.md`

この cluster が言えること:

- 意識経験は身体状態の布置を前提にして立ち上がる
- Layer 0 は一人称経験そのものではなく、その足場を与える
- 身体性を抜いたまま意識経験を論じると、AI と人間の差も曖昧になる

まだ言えないこと:

- どの差異が重要な差として残るか
- その差異がどの軸で評価されるか

返し先:

- 4層モデル: Layer 0 の説明精度を上げる
- 生存-信頼軸: 軸評価の前に身体ベースラインがあることを補助線として示す

### 3-2. 差異の前景化

ここでは、
予測と入力の照合、ズレの選別、前意識的吸収、一部の差異だけが残ることを扱う。

主な source:

- `evidence/review/layer1-prediction-error-reading.md`
- `evidence/review/neurophenomenology-design.md`
- `knowledge/domains/four-layers/part-3-prediction-error.md`

この cluster が言えること:

- Layer 1 は単なる誤差計算ではなく、差異を選別する入口である
- 多くの差異は前意識的に吸収され、一部だけが次段へ送られる
- 一人称の違和感や欠けは、この選別を経たあとに立ち上がる

まだ言えないこと:

- 残った差異が生存軸か信頼軸か
- 残った差異がどの応答方向へ向かうか

返し先:

- 4層モデル: Layer 1 を「欠けそのもの」ではなく「欠けの芽の選別層」として書ける
- 生存-信頼軸: 軸評価以前に、差異が入口で選別されることを前提に置ける

### 3-3. 一人称記述単位

ここでは、
主体にどう経験されているかを first-person として扱い、
説明語彙や計算論は third-person の参照枠として扱う。

主な source:

- `evidence/review/first-person-vs-third-person.md`
- `evidence/review/layer1-prediction-error-reading.md`
- `evidence/review/layer0-interoception-reading.md`

この cluster が言えること:

- `awareness-space` の本論は一人称経験である
- 三人称記述は有用だが、本論そのものではなく参照枠である
- 「意識化された予測誤差」と「欠けとして経験された差異」は同一ではない

まだ言えないこと:

- どの三人称語彙が report にどの程度必要かの最終線
- 個別 report ごとの参照枠の書き分け基準

返し先:

- guide: 一人称経験を先に書き、参照枠を後ろに置く
- report: 既知の経験記述と説明語彙を混ぜない

### 3-4. 前反省的気づき

ここでは、
身体感覚でも評価済み判断でもない、
評価以前の気づきや前景化の最小単位を扱う。

主な source:

- `evidence/review/neurophenomenology-design.md`
- `evidence/review/layer0-interoception-reading.md`
- `evidence/review/layer1-prediction-error-reading.md`

この cluster が言えること:

- 前反省的気づきは、Layer 0 の身体足場と Layer 1 の差異選別の間にまたがる
- それは完成した判断ではなく、まだ名づけ切られていない経験単位として扱うのが妥当である

まだ言えないこと:

- 4層モデルのどこで固定的に受け持つか
- 前反省的気づきを独立構成要素として公開すべきか

返し先:

- survey: 現在検討中の論点として示す
- design: 層対応を急いで固定しない前提を残す

## 4. source の受け取り方

神経現象学系 source は、次の順で intake する。

1. まず一人称経験の問いを置く
2. 次に身体性と差異の前景化を読む
3. その後で三人称参照枠を補助線として使う
4. 最後に、生存-信頼軸や4層モデルへ返せる論点だけを戻す

この順序を逆転させて、
計算論的語彙から一人称経験を定義しない。

## 5. report / guide / survey への返し方

### report に返せるもの

- Layer 0 を身体的足場として読む整理
- Layer 1 を差異の選別層として読む整理
- 一人称記述と三人称参照枠の書き分け原則

### survey に返すもの

- 神経現象学接続は整備中であること
- 身体性、差異の前景化、前反省的気づきが主要な論点であること

### guide に返すもの

- 意識経験は最初から抽象的な思考ではなく、身体と差異の前景化を足場にすること
- ただし神経現象学は参照枠であり、完成理論として採用したわけではないこと

### まだ返さないもの

- 脳部位対応の断定
- Friston 系参照枠の本論化
- 前反省的気づきの層対応の固定

## 6. 未確定論点

1. 前反省的気づきを 4層モデルのどこへ置くのが最も自然か
2. 生存-信頼軸の評価開始点を Layer 1 とどう切り分けるか
3. report ごとに三人称参照枠をどの程度まで書くか
