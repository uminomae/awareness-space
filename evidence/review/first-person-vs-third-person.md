# first-person vs third-person

`#51` の整理メモ。

この文書は、
`awareness-space` で意識を記述するときに、
**一人称経験の記述**と**三人称の計算論的記述**をどう区別するかを明文化する。

## 1. このメモの問い

どこまでを現象学的な一人称記述と呼び、
どこからを参照枠としての三人称記述と呼ぶべきか。

## 2. 基本区別

### 2-1. 一人称記述

一人称記述とは、
主体にとって「どう経験されているか」を記述する水準である。

例:

- 何かが足りないと感じる
- いつもの温かさがない
- 逃げたいが動けない
- 自分が自分でない感じがする

`awareness-space` が主語にするのは、まずこの水準である。

### 2-2. 三人称記述

三人称記述とは、
外部から現象を説明するための計算論的・生理学的・理論的な水準である。

例:

- 予測誤差信号が閾値を超えて伝播する
- precision weighting が変化する
- 島皮質が身体状態を統合する
- vmPFC と扁桃体系の接続が関与する

この水準は有用だが、
`awareness-space` では本論そのものではなく**参照枠**として扱う。

## 3. D2 における区別

core-definitions の D2 は、
この区別を最も明確に表している。

- 3人称: 予測誤差が計算され、精度閾値を超えて上位層に送られる
- 1人称: 予想と現実の誤差が「欠け」として経験される

重要なのは、
「意識化された予測誤差」と
「欠けとして体験された予測誤差」を同一視しないことだ。

前者は説明語彙であり、
後者が `awareness-space` の主題である。

## 4. Layer 0 / Layer 1 の位置づけ

### Layer 0

- 身体性の足場を与える
- ただし Layer 0 自体はまだ「欠損」を作らない

つまり Layer 0 は、
一人称経験の前提条件を与える層であり、
まだ一人称経験そのものを言い切る層ではない。

### Layer 1

- ズレを検出する
- 多くのズレを前意識的に吸収する
- 一部を欠損の芽として次層へ送る

つまり Layer 1 は、
一人称経験へ至る直前の境界層である。

## 5. Friston 系参照枠との関係

Friston 系の語彙は、
Layer 1 を理解するためには有用である。

使える点:

- 予測と入力の照合
- 精度 / 注意 / 更新
- 更新と行動の分岐

ただし、そのまま採らない点:

- 誤差最小化を本論の目的関数にしない
- 一人称経験を三人称の情報処理へ還元しない
- Containment を単なる抑制や最適化にしない

## 6. awareness-space での書き分け原則

### 原則 A

主語はまず一人称経験に置く。

### 原則 B

三人称の語彙は「参照枠」「説明語彙」「相関物」として明示する。

### 原則 C

脳部位 = 機能 の断定を避ける。

### 原則 D

計算論的記述を使うときは、
それが何を照らし、何をまだ照らしていないかを書く。

## 7. guide / report への含意

### guide

- 一人称経験を先に書く
- 参照枠は補助として後ろに置く

### report

- 既知と仮説を分ける
- 1人称と3人称の区別を混ぜない

### review / design

- 参照枠の使い方そのものを明文化する
- 還元しすぎた場合はここで止める

## 8. 結論

`awareness-space` では、
一人称経験が本論、
三人称記述は参照枠である。

Layer 0 と Layer 1 は、
その境界へ至る前提と入口を与えるが、
一人称経験をそのまま置き換えるものではない。
