# intake return map

神経現象学 intake と発達心理学 intake を、
`awareness-space` の guide / survey / report / design memo のどこへ返すかを固定する正本。

## 1. 目的

- intake map の論点を公開物ごとの返し先へ割り振る
- guide が何を弱く書けて、report が何を強く書けるかを揃える
- survey に残すべき「整備中」の論点を固定する
- design memo に残す論点を、report へ早出ししないようにする

## 2. 返し先の原則

| 返し先 | 置いてよいもの |
|---|---|
| guide | 現時点の有力な見解、比較的安定した補助線、調査中であることの明示 |
| survey | 進行中の論点、未整備領域、読むべき順序、現在地 |
| report | 既存 report の主題に直接返せる整理、reader-facing に読める論拠 |
| design memo | まだ固定しない層対応、語彙選定、観測設計、返し先未確定論点 |

## 3. 神経現象学 intake の返し先

| intake cluster | guide | survey | report | design memo |
|---|---|---|---|---|
| 身体性の足場 | 意識経験は身体を足場にする、と弱く書く | 神経現象学接続の主要論点として継続表示 | `four-layers` report に Layer 0 の補助線として返す | 身体性をどこまで中心語彙に入れるか |
| 差異の前景化 | 差異が前景化して経験される、と弱く書く | Layer 1 接続が整備中だと示す | `four-layers` report に Layer 1 の選別層として返す | どの差異が信頼軸 / 生存軸へ渡るか |
| 一人称記述単位 | 本論は一人称経験で、三人称語彙は参照枠だと書く | report への返し方を整備中と示す | `four-layers` report と guide の書き分け原則へ返す | report ごとの参照枠の強さ |
| 前反省的気づき | 強くは返さない | 検討中の未確定論点として残す | まだ返さない | 4層内の位置づけ、独立要素化の要否 |

## 4. 発達心理学 intake の返し先

| intake cluster | guide | survey | report | design memo |
|---|---|---|---|---|
| 愛着と安全基地 | 関係の安定が探索可能性の条件だと弱く書く | 発達心理学接続の主要論点として表示 | `survival-trust-axis` report に信頼軸の発達基盤として返す | 信頼軸の中心語との距離 |
| 内的作業モデル | 関係経験の蓄積が働くと弱く書く | 主要論点として継続表示 | `survival-trust-axis` report に関係安全性の背景条件として限定的に返す | どこまで中心語彙に入れるか |
| 信頼と間主観性 | 中心語未固定だと明示して弱く触れる | 候補語の比較中だと示す | まだ主軸 report へは限定的に返す | 中心語の選定、reader-facing 前面化の可否 |
| 修復可能性と関係調整 | 関係は壊れないことより修復可能性が重要だと弱く書く | 主要な検討点として残す | `survival-trust-axis` report に観測可能性候補として限定的に返す | 信頼軸の観測指標としての扱い |

## 5. 既存 report への返し方

### 5-1. `survival-trust-axis`

- 発達心理学 intake から主に返す
- 愛着、安全基地、内的作業モデル、修復可能性を信頼軸の背景条件として返す
- 中心語の断定はしない

### 5-2. `four-layers`

- 神経現象学 intake から主に返す
- 身体性、差異の前景化、一人称 / 三人称の書き分けを返す
- 前反省的気づきの固定配置はまだ行わない

## 6. survey に残すもの

- 神経現象学接続は身体性 / 差異の前景化 / 前反省的気づきが主要論点である
- 発達心理学接続は愛着 / 安全基地 / 内的作業モデル / 間主観性 / 修復可能性が主要論点である
- 返し先未確定の論点は survey で「整備中」として残す

## 7. design memo に残すもの

- 前反省的気づきの層対応
- 信頼軸の中心語選定
- 修復可能性をどこまで観測指標にするか
- report ごとの三人称参照枠の強さ

## 8. 完了条件

- 神経現象学 / 発達心理学 intake の各 cluster について、返し先が表で説明できる
- `survival-trust-axis` と `four-layers` のどちらへ主に返すかが固定される
- guide / survey / report / design memo の境界を崩さずに説明できる
