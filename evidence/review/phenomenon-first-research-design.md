# phenomenon-first research design

`awareness-space` の調査を、
既存ラベル中心の再配置から、
現象先行・evidence-first の探索へ組み替えるための設計メモ。

この文書は `awareness-space#72` の作業メモであり、
後続の再読・概念監査・公開再生成の入力とする。

## 1. 基本方針

調査の順序を次に固定する。

1. 現象を抽出する
2. 境界を確認する
3. 近縁現象と分ける
4. 命名可能性を判定する
5. 必要なら命名する
6. 命名済み概念だけを公開配置する

この順序を崩して、
既存ラベルに合わせて現象を寄せることを禁止する。

## 2. 現時点で凍結するもの

次のラベルは、調査途中では**仮トークン**として扱う。

- `Withhold`
- `生存-信頼軸`
- `4層モデル`

凍結の意味:

- 中核概念として先取りしない
- 独立 report の存在を概念成立の根拠にしない
- 再読時の抽出カテゴリとして使わない
- 抽出メモでは中立 ID を優先する

## 3. 抽出単位

調査で最初に扱う単位は「概念」ではなく「現象断片」とする。

各断片は仮に `P-001`, `P-002` のような ID で記録する。

最低限、各断片に次を持たせる。

- 現象記述: 何が起きているか
- 文脈: どの条件で起きるか
- 成立条件: 成立に必要な前提は何か
- 不成立条件: 何が欠けると成立しないか
- 近縁現象: 何と混同しやすいか
- 反例 / 境界例: 同じ名前で呼べない例は何か
- source: どの文書・読解に由来するか

## 4. 初期の主質問

調査設計上の主質問は、既存ラベルではなく次で立てる。

### Q1. 反応以前にどのような差異が立ち上がるのか

- どのズレが前景化するのか
- 何が一人称的な「気になる」に変わるのか

### Q2. その差異はどのような方向づけを受けるのか

- 身体的危険
- 関係的断絶
- 評価不能
- 意味未形成

ここではまだ「二軸」と決めない。

### Q3. すぐ反応しない現象には、どのような種類があるのか

- 凍結
- 抑制
- 保留
- 観察
- 再評価可能な保持
- 共同での保持

ここではまだ `Withhold` と命名しない。

### Q4. 上記の現象は何を条件に成立するのか

- 身体状態
- 愛着 / 安全基地
- 関係安全性
- 文脈
- 支援者 / 場

## 5. 命名可能になる条件

現象群に名前を与えてよいのは、次を満たした場合に限る。

1. 近縁現象との差分を説明できる
2. 反例または境界例を少なくとも1つ示せる
3. 成立条件を少なくとも2つ示せる
4. 異なる source からの支持がある
5. 読者向けに1段落で誤解なく要約できる

1つでも欠ける場合、そのラベルは保留または分解候補とする。

## 6. 公開ゲート

reader-facing な独立 report を与えてよいのは、次を満たす場合のみ。

1. 命名条件を満たしている
2. evidence 束が複数 source で確認できる
3. その概念を独立させる理由がある
4. 調査中の仮説ではなく、少なくとも暫定境界がある

満たさない場合は、次のいずれかに落とす。

- design memo
- source bundle
- overview 内の未確定論点
- 調査計画 issue

## 7. 既存公開物への適用ルール

### A. survey

- 既存ラベルの一覧ではなく、調査質問の一覧を先に出す
- 「何が確定 / 未確定か」を先に出す

### B. guide

- summary は概念の安定度を隠さない
- 独立 report がないものを論拠済みと見せない

### C. report

- 独立概念として未成立のものは report から降格する
- 既に report がある場合でも、監査中は仮説ラベルと明記する

### D. manifest

- card は概念の成熟度を隠さない
- 必要なら `report_ready` から `source_ready` へ戻す

## 8. 後続 issue への受け渡し

### `#73`

- ラベルを使わず `P-xxx` 単位で現象を抽出する
- 特に「すぐ反応しない」現象を分解して記録する

### `#74`

- 抽出結果をもとに `Withhold` を維持 / 分解 / 廃棄 / 保留で判定する
- `生存-信頼軸` と `4層モデル` も同様に境界監査する

### `#75`

- 命名条件と公開ゲートを満たしたものだけを reader-facing に残す
- 調査中の概念は design memo または source bundle へ戻す

## 9. 暫定結論

`awareness-space` の次段階で必要なのは、
既存ラベルを磨くことではなく、
**ラベルの下にある現象を再抽出するための順序を固定すること** である。

とくに `Withhold` は、
ここから先は独立概念として扱うのでなく、
「すぐ反応しない現象群を仮に指している候補名」として扱う。
