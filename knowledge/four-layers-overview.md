# 4層モデル 概説

`awareness-space` における意識モデル解説の入口文書。

旧称: M1 意識OS。現在は独立概念ではなく、4層モデルの原著文書群として同じ枠内で扱う。

## これは何か

4層モデルは、意識の作動を次の4つの層で記述する枠組みである。

1. Layer 0: 内受容感覚
2. Layer 1: 予測-誤差ループ
3. Layer 2: 生存-信頼評価
4. Layer 3: Withhold

このモデルは、意識を「何かが分かったあとに説明するもの」ではなく、
ズレを検出し、価値づけし、保持する処理の連なりとして捉える。

## なぜ重要か

このモデルの強みは、
意識を静的な箱ではなく、段階的な作動として読める点にある。

- 身体状態がどこで関わるか
- 予測と現実の差がどこで立ち上がるか
- 情動や行動準備がどこで方向づけられるか
- 反応を保留して見直す余地がどこにあるか

を、一つの流れとして整理できる。

## 各層の役割

### Layer 0

身体の状態を知る層。心拍、呼吸、緊張、内受容感覚の足場。

### Layer 1

予測と現実のズレを検出する層。
ここで、いま起きていることが想定と合っているかどうかが前景化する。

### Layer 2

ズレに情動価を与える層。
生存軸 / 信頼軸で評価し、行動準備を方向づける。

### Layer 3

評価済みの行動準備を、即座に反応へ流さず保持する層。
