# 生存-信頼軸 起点メモ

`awareness-space` における最初の探索メモ。
本メモは、Issue `awareness-space#2` の成果物として、生存-信頼軸をこの repo の出発点としてどう置くかを明文化する。

## 1. 位置づけ

生存-信頼軸は、`awareness-space` における最初の中核仮説である。

親 Issue `kesson-driven-thinking#280` では、次のように指示されている。

- **生存-信頼軸 — 生存（生存軸）と間主観性（信頼軸）を基礎とする意識の仮説**

この repo は、この仮説を最初から確定理論として扱うのではなく、**探索の起点**として扱う。

## 2. このメモでの最小定式化

現時点では、生存-信頼軸を次のように置く。

- 人間の意識経験は、ズレや欠損を単に検出するだけではなく、それを**少なくとも二つの方向**で評価している
- 第一の方向は **生存軸** であり、生存、脅威、安全、身体的・社会的な危険回避に関わる
- 第二の方向は **信頼軸** であり、関係、愛着、所属、信頼、間主観的なつながりに関わる
- 情動や行動準備は、この二軸での評価を通じて方向づけられる

この意味で、生存-信頼軸は「感情の分類表」ではなく、**意識が何を重要なものとして扱うかを分ける最小座標系**として仮置きする。

## 3. 既存正本との接続

### 3-1. D4 との接続

`kesson-driven-thinking` の正本定義では、D4 は次の通り。

- 欠損が生存軸（生存）と信頼軸（愛）で評価され、情動として構成されるプロセス

`awareness-space` では、この定義をそのまま移植するのではなく、出発点として参照する。
少なくとも現段階では、生存-信頼軸は以下の二点を含む。

1. 欠損やズレは、評価される
2. その評価は 生存軸 / 信頼軸 の二軸で記述できる

### 3-2. 4層モデル原著文書群との接続

`knowledge/topics/four-layers/ja/report.md` では、4層モデルのうち Layer 2 に相当する役割が次のように整理されている。

- Layer 1 から送られたズレを、生存軸（生存・脅威）と 信頼軸（愛着・所属）で評価する
- その評価が情動価を与え、行動準備として Layer 3 に送られる

ここから `awareness-space` が引き取るべき点は、神経基盤の細部ではなく、
**意識経験はズレを評価する段階で、すでに 生存-信頼 の方向づけを受けている**
という構造仮説である。

### 3-3. CN-002 との接続

`CN-002_f-axis-exposure.md` は、生存軸の条件を完全に遂行しても 信頼軸の欠損が解消しない体験を扱う。

このノートは `awareness-space` にとって重要である。理由は次の通り。

- 生存軸と 信頼軸は、単なる並列カテゴリではない
- 人間はしばしば 信頼軸の問題を 生存軸の達成で解こうとする
- その誤配が露出する体験は、意識探索の核心素材になりうる

したがって、生存-信頼軸は「二分類」ではなく、**取り違え、代用、乗っ取り、露出**を含む動的な座標系として扱う必要がある。

## 4. 現時点での作業仮説

現時点では、次の作業仮説を採用する。

1. 意識は、ズレや欠損を 生存軸 / 信頼軸 で評価することで情動価を与える
2. 生存軸は「生存の確保」に関わるが、身体的脅威だけでなく、地位、資源、防衛も含みうる
3. 信頼軸は「間主観的なつながり」に関わり、愛着、所属、信頼、承認、理解されることを含みうる
4. 人間の苦しさの多くは、信頼軸の問題を 生存軸で処理しようとする構造的な誤配から生じる
5. 評価結果をただちに反応へ流さず、問いとして留め直す保持条件がありうる

## 5. スコープ

このメモで扱うスコープは限定する。

### 扱う

- 生存-信頼軸を `awareness-space` の起点仮説として置くこと
- D4、4層モデル Layer 2 文書、CN-002 との最小接続
- 今後の探索で何を見に行くべきかの方向づけ

### まだ扱わない

- 生存軸 / 信頼軸 の最終定義の確定
- 信頼軸を「愛」と呼ぶか「間主観性」と呼ぶかの最終決定
- 神経基盤の確定
- 生存軸 / 信頼軸 以外の第三軸が必要かどうかの最終判断
- 臨床・発達・社会理論まで含めた統合モデル

## 6. 非スコープ

このメモは以下をまだ主張しない。

- 生存-信頼軸だけで意識の全体が説明できる
- すべての情動が常に二軸へ綺麗に還元できる
- 信頼軸の内容が「愛」で確定している
- `kesson-driven-thinking` の理論記述を、そのまま `awareness-space` の正本にする
