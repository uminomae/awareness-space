## 本文書の位置づけ

本文書は「意識の作動構造」Phase 3の導入部である。Phase 3全体の目的、4層モデルの概要、各層間のインターフェース、および後続Partへのロードマップを提示する。

本プロジェクトの主張の中心は、特定の理論（例：予測符号化）そのものではなく、**欠損（Kesson）という一人称的現象が「問い」として機能し、保持（Withhold）を経て創造に接続される**という処理系の記述である。神経科学や現象学的語彙は、その処理系を照らすための参照枠・類似性の紹介として用いるが、説明の独占権を与えない。
各Partでは参照枠の比重と粒度を意図的に変える。必要な箇所では神経科学・理論語彙を用いるが、常に「本論（欠損→評価→保持）」を主語に保つ。

**レイヤ分離**：
- **[P]** Physics/Physiology: 実験的事実・観察可能な相関物
- **[M]** Metaphor: 発想の起点となる比喩・解釈・図式
- **[S]** Speculation: 検証可能な仮説（反証可能性を持つ）

## 1.1 Phase 3の目的

### 1.1.1 「意」とは何か

**[M]** 本プロジェクトにおける「意」とは、思考・推論・記憶（高次認知）とは**別の層**に位置する、意識の基本的な作動構造である。

**[M]** 「意」の特徴：
- 睡眠夢でも発動する**基本機能**
- 高次認知の**前提条件**として作動する
- 身体と世界の**インターフェース**として機能する

### 1.1.2 Phase 3で何をするか（何をしないか）

**[S]** Phase 3の目的は、「意」の作動構造を**4層の機能モデル**として提示し、欠損駆動思考（Kesson-Driven Thinking）の中核ループ（欠損→評価→保持）に接続することである。具体的には：

1. 「意」を構成する層（Layer 0〜3）を機能的に分離する
2. 各層の入出力と、層間のインターフェースを定義する
3. 欠損（問いの芽）→情動価（評価）→保持（Withhold）の連鎖を、モデルとして最小限に記述する
4. 神経科学・臨床・哲学などの論拠を並置し、**類似性と差異**を明示する（単一理論へ還元しない）

**[S]** 本Phaseが「しないこと」：
- 4層を、ある特定理論の用語体系へ一対一に**翻訳**すること
- 4層の全要素を、現時点の神経科学で**完全に確定**すること
- 一人称的経験を、三人称的記述へ**還元**して置き換えること

### 1.1.3 参照枠の位置づけ（主張の重心）

**[M]** Phase 3では、次のように重心を置く：

| 役割 | 例 | 本文での扱い |
|---|---|---|
| 本論（中核） | 欠損の否定性／問いの構造／保持（Withhold） | 体験記述と作動モデルを主語にする |
| 参照枠（鏡） | 予測-誤差・精度・注意などの神経科学的語彙 | 類似点と相違点を示す（脇役） |
| 補助的論拠 | 睡眠夢、臨床概念、哲学（自己・否定性等） | それぞれの射程と限界を明記して併置 |

## 1.2 4層モデルの概要

### 1.2.1 なぜ4層か

**[S]** 「意」の構造を分析した結果、以下の4つの機能的に区別可能な層が特定された：

| Layer | 名称 | 機能 | 時間スケール |
|-------|------|------|-------------|
| **0** | 内受容感覚 | 身体モニタリング | ミリ秒（連続） |
| **1** | 予測-誤差ループ | ズレ（違和感）の検出（欠損の芽） | ミリ秒 |
| **2** | F-O評価 | 価値判断（情動価の付与） | 数百ミリ秒 |
| **3** | Withhold | 行動制御（保持・再評価・実行） | 秒単位 |

**[P+M]** Layer 2とLayer 3を分離した理由：
- **Layer 2（F-O評価）**：自動的・高速・情動的価値の付与（扁桃体等を参照枠として想定）
- **Layer 3（Withhold）**：意図的・低速・保持と再評価（前頭前野等を参照枠として想定）

時間スケールと機能が異なるため、単一層として扱うのは不適切である。

### 1.2.2 4層の参照枠（神経基盤：暫定）

**[P]** 各層に関して、現時点で参照可能な中心領域（相関物の候補）：

| Layer | 参照枠（暫定） |
|-------|---------|
| 0 | 島皮質（後部→前部） |
| 1 | 皮質階層全体（浅層：誤差、深層：予測） |
| 2 | 扁桃体（F軸）、vmPFC・前部島皮質（O軸） |
| 3 | dlPFC、ACC、rIFG |

**注意**：上表は「4層そのもの」を確定するものではなく、4層が指し示す現象と整合する可能性がある参照枠である。

## 1.3 層間インターフェース

### 1.3.1 情報の流れ

**[M]** 4層間の情報の流れ：

```
外界 + 身体
    ↓
Layer 0 → 身体状態表象
    ↓
Layer 1 → ズレ（違和感）（欠損の芽）
    ↓
Layer 2 → 評価（情動価） + 行動準備
    ↓
Layer 3 → 実行・保持継続・再評価要求
    ↓
行動 または フィードバック（Layer 2へ）
```

### 1.3.2 各インターフェースの特徴

| インターフェース | 渡されるもの | 特徴 |
|----------------|-------------|------|
| L0 → L1 | 身体状態表象 | 連続的、遮断不可 |
| L1 → L2 | 選別されたズレ（違和感） | 選択的（多くは棄却される） |
| L2 → L3 | 評価済みズレ + 行動準備 | 情動的価値を含む |
| L3 → 行動/L2 | 実行・保持・再評価要求 | 制御信号 |

## 1.5 欠損駆動ループとの接続

**[S]** 4層モデルは、欠損駆動ループの前半部分に対応する：

| 欠損駆動ループ | 4層モデル |
|---------------|----------|

**[S]** Withholdの後、欠損は「創造5段階」（場→波→縁→渦→束）へと渡される（Phase 2で詳述）。

## Part 1 まとめ

**[S]** Phase 3では、「意」の作動構造を4層モデルとして提示する：

- **Layer 0**：身体の「今」を知る（内受容感覚）
- **Layer 1**：「違う・足りない」を検出する（欠損の芽）
- **Layer 2**：「良い・悪い」を与える（情動価）
- **Layer 3**：「待つ・保持する」を可能にする（Withhold）

この4層が協働することで、衝動的反応ではなく、創造的応答が可能になる。
