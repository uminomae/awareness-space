# 意識モデル 総覧

`awareness-space` の「意識モデル」セクションをまとめて読むための総覧。

## 1. このセクションは何を扱うか

意識モデルセクションは、意識をどう記述するかの基盤となる概念群を整理する。
現時点では、次の4本を主要入口としている。

1. F-O軸
2. 4層モデル
3. Withhold
4. M1 意識OS
5. Concept Notes

## 2. F-O軸

F-O軸は、意識経験を読むときに、
何を守ろうとしているか、何とのつながりを保とうとしているかを見分けるための最小座標系である。

- F軸: 生存、脅威、安全、保身
- O軸: 関係、愛着、所属、信頼、間主観性

入口:
- `fo-axis-overview.md`

## 3. 4層モデル

4層モデルは、意識の作動を Layer 0〜3 の4層で捉える。

- Layer 0: 内受容感覚
- Layer 1: 予測-誤差ループ
- Layer 2: F-O評価
- Layer 3: Withhold

入口:
- `four-layers-overview.md`

## 4. Withhold

Withhold は、評価済みの行動準備を即座に実行せず、問いとして保持する機能である。

入口:
- `withhold-overview.md`

## 5. M1 意識OS

M1 意識OSは、意識の作動構造を整理した文書群であり、4層モデルや F-O軸 の土台になる。

入口:
- `m1-consciousness-os-overview.md`

## 6. Concept Notes

Concept Notes は、
意識モデルを補助する概念や境界事例を集めたノート群である。
主軸の解説だけでは見えにくい論点を追うときの入口になる。

入口:
- `concepts-overview.md`
