# docs/guardian-matrix.md

`awareness-space` の最低限の守護者マトリクス。

| ID | ルール | 守護対象 |
|---|---|---|
| AW-001 | `knowledge/`, `evidence/`, `transform/`, `docs/` の役割分離を守る | 構造 |
| AW-002 | report と計画書を混同しない | コンテンツ |
| AW-003 | `creation-space` 模倣時に、見た目だけでなく workflow も確認する | パイプライン |
| AW-004 | 移設は awareness 側に実体を持ってから議論する | 移設計画 |
| AW-005 | guide は summary であり、主要な要点は report / survey / design memo に対応づける | 解説品質 |
| AW-006 | report のない主張を、調査済みの説明として guide に書かない | 検証境界 |
| AW-007 | UI は summary と論拠の関係を読者が辿れる形で示す | UI導線 |
