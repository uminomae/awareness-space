## index.html

「意識とは」ランディング。生存-信頼軸仮説 + 風神雷神背景 + MODEL / NOTES / RESEARCH 三層セクション。kesson / creation と共通骨格だが、wiki への外部リンク所持、about-overlay modal、image-card-grid（notes）が独自。

### レイアウト
- **Three.js canvas + content の z-index 分離**: kesson / creation と同パターン。KEEP
- **`body.awareness-page` class**: repo 固有の page-level scope hook。KEEP
- **section 連鎖**（model / notes / reports）: 意識モデル → 発散思考 note → 調査。kesson の3 repo 比較で **content type が異なる**（kesson: guides/research/articles, creation: model/reports/cross-analysis/articles, awareness: model/notes/reports）。KEEP — 各 repo の調査段階と一致
- **`#graphic-switcher` は button 1個（風神雷神）のみ**: creation の忍/意 2択より絞られている。KEEP — 公開段階では 1 モードに絞る判断
- **about-overlay（`i` button → 全画面 modal with about-glass）**: 他 repo にない独自 UX。「このページについて」を常時可視化する小さな入口。KEEP
- **site-offcanvas（右スライド、section list）**: 現在 `MODEL` のみ。セクションへの近道。KEEP
- **dev-components-link** 固定位置: 開発 navigation を本番画面にも置く。KEEP（運用中の dev route として意図あり）

### アニメーション
- **room-narration 幕間**（3 箇所、narrations.* dict 経由）: kesson/creation と共通。詩的配置、アニメなし。KEEP
- **graphic-switcher 静的配置**（aria-pressed の toggle のみ）: creation と同方針。KEEP
- **about-overlay 開閉**: 本文では CSS transition 推定（about-modal.css に記述）。要確認だが、一般的に `transform` + `opacity` fade 前提。KEEP
- **`#hero-spacer` によるスクロール余白**: kesson/creation と共通。KEEP

### 配色
- **tokens.css の core は kesson/creation と同一**: `--color-accent: 100, 150, 255` 等。SYSTEMIZE（pd 集約の最優先）
- **`"Intentional difference vs creation-space: tighter UI type and stronger accent-backed action colors"`** コメント明記: awareness は creation より **UI フォントを小さく**、**action 系の accent 背景を濃く**する方針。KEEP — 明示された差分
- **topbar 系 tokens が 0.80rem 揃え**（link/note/credit/meta など、creation は 0.88rem が多い）: 調査系ページの情報密度を下げない判断。KEEP
- **`--kesson-md-*` tokens 一式**（h1-h4, link, quote, inline-code, table, pre, pdf-link 等、約 18 個）: reports の md modal 用。KEEP — repo の本業（調査 md 表示）と一致、SYSTEMIZE 候補（pd の wiki compiled layer と重複する可能性）
- **Raijin palette**（`linear-gradient(135deg, #061824, #0d6d67, #7df6ff)`）: 青緑の漸次、風神雷神の「雷」色。KEEP — awareness 固有のアイデンティティ
- **Uzu palette**（`linear-gradient(135deg, #d1deef, #90abc8, #001543, #0099ff)`）: 淡 → 深青 → 電気青、「渦」色。dev-components でのみ公開。KEEP（#28 由来の DEV palette）
- **`--kesson-action-bg: rgba(accent, 0.1)` + `--kesson-action-border: rgba(accent, 0.2)`**: creation の action-border (0.1) より濃い。KEEP（明示された差分）

### タイポグラフィ
- **Noto Serif JP + SF Mono（二本柱）**: creation の三本柱（+Noto Sans JP）から sans を除外。awareness は明朝 + mono で「静かな調査感」を強調。KEEP — 明示された差分
- **`--kesson-topbar-link-size: 0.80rem`**: creation より小さい。KEEP
- **`--kesson-section-heading: 0.88rem / --kesson-card-title: 1.0rem / --kesson-card-text: 0.92rem`**: kesson/creation と同一スケール。SYSTEMIZE
- **`data-i18n-html` による `<br>` 改行制御**: creation と共通。KEEP
- **`heroTaglinePrimary / heroTaglineSecondary` dual tagline**: h1 前に 2 行テキスト。kesson/creation と違い、hero 内に明文化された「問い」がある（"生存と間主観性から、意識を捉え直す。"）。KEEP — 理論的姿勢の表明

### 触覚的要素
- **about-trigger の `i` ボタン**: 円形（推定）、letter 1 文字の極小 UI。KEEP — ブランド強度高い小道具
- **about-glass（`about-overlay` 内）**: viewer-glass と同 pattern の透過パネル。SYSTEMIZE（viewer-glass との統合候補）
- **`--kesson-card-shadow-soft / -rich`** 2段: creation / kesson と共通。SYSTEMIZE
- **dev-components 冒頭の radial-gradient bg**（`circle at top left, rgba(46, 72, 116, 0.24), transparent 40%` + `linear-gradient` base）: creation と似た radial + linear 組合せ。KEEP
- **ds-hero / ds-card の `box-shadow: 0 20px 60px rgba(0, 0, 0, 0.26)`**: creation と完全一致。SYSTEMIZE（3 repo 共通化可）

### インタラクション
- **i18n 方式: `data-i18n` + `data-i18n-attr-*` + `data-i18n-html`**: creation と同方式。KEEP — creation と統一されており、kesson との差異は維持されたまま
- **graphic-switcher aria-pressed**: creation と共通。SYSTEMIZE
- **font-size-down/reset/up + lang-toggle**: creation と共通。SYSTEMIZE
- **about-overlay の modal 開閉**（`data-modal-open="about" + data-about-close` 属性 hook）: 独自 attribute-driven modal。KEEP — 独自に見えるが属性駆動は他 repo に展開可能
- **Wiki 外部リンク（topbar, reports-md-modal）**: awareness は pd wiki への依存を明示化。KEEP
- **reports-md-modal の 3 button header**（PDFを開く / Wiki を開く / Close）: awareness 固有の action set。KEEP
- **`#offcanvas-model-link` 単一 link**: offcanvas 内にまだ MODEL リンクのみ。DROP 候補（機能未使用、削除か拡充か判断）

### index.html 特有の所見
- **creation / awareness の i18n 方式は統一**（kesson だけ別方式）: 3 repo のうち 2 が一致。kesson を寄せるのが自然
- **Three.js 0.160.0 は kesson/creation の 0.183.0 より古い**: 意図的保持なら KEEP、更新忘れなら DROP / 更新。B フェーズの前に確認すべき
- **風神雷神 single mode は公開絞り込み**: dev-components で `?graphic=uzu` が開ける。Uzu は「調査中の渦」モード → 公開前夜感
- **wiki 連携の明示（topbar と md modal の両方）**: awareness が「調査 → 用語」の二層で構成されている証拠。pd の wiki compiled layer と直結する設計

### 判断の非自明点

- **Three.js バージョン差**（awareness: 0.160.0, kesson/creation: 0.183.0）: 意図か技術負債か B 判断
- **`"Intentional difference vs creation-space"` コメント**: creation にも `"vs awareness-space"` コメントがあり、**両方向から差分を意識的に記録**。pd 集約時に 「差分の非対称性を許容するか」（creation → awareness / awareness → creation の両方向で override 可能にするか）
- **awareness は明朝+mono の二本柱、creation は +sans の三本柱**: 絵文字的に言うと、awareness は「静」、creation は「動」。これをブランド差として保持するか、unification するか
- **about-overlay（i button）は awareness 固有のブランド要素**: 他 repo に展開するか個性として残すか
- **`--kesson-topbar-*` が topbar のサイズを 0.80rem に寄せ**: 情報密度を上げる方針だが、モバイルで可読性が落ちる可能性 → 実機確認が B の課題

### 気づき（観点B で先に決めたほうが良いこと）

- **3 repo の tokens.css がほぼ同一だが、各 repo に完全コピーがある**: pd 集約すれば **差分 override のみ** を各 repo に置く構造になる。awareness の「intentional difference」コメントが正にこの構造を前提にしている
- **`--kesson-md-*` tokens が awareness で 18 個ある**: pd の wiki compiled layer で md renderer を共通化する場合、この token 群を共有資産にする価値高い
- **about-overlay の `data-modal-open` / `data-about-close` 属性駆動 modal**: Bootstrap modal に依存しない軽量 modal pattern。SYSTEMIZE 候補（全 repo の軽量 modal 運用に展開可能）
- **dev-components.html が 3 repo で重量差（kesson 770行 / creation 1414行 / awareness 128行）**: 統合の方向性を先に決めないと「どの粒度で集約するか」が決まらない。awareness 方式（叩き台叙述）、kesson 方式（仕様 table）、creation 方式（実行カタログ）— 3 つのうちどれを正本にするか
