# Standing Approvals

ユーザーから明示的に出た「以後も承認する」運用上の許可メモ。

## 注意

- これは**ローカル運用メモ**であり、sandbox / tool の制度的承認そのものではない
- 実行環境が追加承認を要求する場合は、その要求を優先する

## 現在のメモ

### 2026-03-18

- `awareness-space` repo 内では、更新・commit・push を自律的に進めてよい
- Issue 完了時の comment / close は自律的に進めてよい
- この対話で許可したコマンドは、**同種の repo 内作業であれば以後も承認済みとして扱う**

### 対象の解釈

主に次を含む:

- `git add`
- `git commit`
- `git push`
- `gh issue comment`
- `gh issue close`
- repo 内の検証用コマンド
- repo 内の不要な検証残骸の削除

必要なら次セッションでここを更新する。
