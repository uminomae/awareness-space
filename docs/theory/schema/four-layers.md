# 意識の4層モデル（Four Layers）

**最終更新**: 2026-04-08  
**状態**: 構造記述に専念（脳部位参照枠を削除、techo#105）

---

## 概要

意識の作動構造を4層で記述するモデル。M1（意識OS）の核心。

神経科学的な対応物については原典 wiki を参照。本スキーマは「欠損→評価→保持」の処理系の構造記述に専念する。

---

## 4層一覧

| Layer | 名称 | 機能 |
|-------|------|------|
| 0 | 内受容感覚 | 身体モニタリング |
| 1 | 予測-誤差ループ | ズレ検出、欠損生成（選別） |
| 2 | 生存-信頼評価 | 価値判断（情動価の付与） |
| 3 | 抱持 | 行動制御（保持） |

---

## 情報の流れ

```
外界 + 身体
    ↓
Layer 0: 内受容感覚（身体の「今」を知る）
    ↓ 身体状態表象
Layer 1: 予測-誤差ループ（ズレ（違和感）を検出）
    ↓ 選別を通過 → 「欠損」として立ち上がる
Layer 2: 生存-信頼評価（情動価を与える）
    ↓ 情動 + 行動準備

══════【意のゲート】══════

Layer 3: 抱持（「待つ・保持する」を可能にする）
    ↓
実行・保持継続・再評価要求
```

## 各層の詳細

### Layer 0: 内受容感覚

**機能**: 身体モニタリング

身体内部の状態（心拍、呼吸、内臓感覚等）をモニタリングする。

**関連概念**:
- Craig: 内受容感覚と意識
- 五蘊の「色」「受」

**E07との関係**: 「身体が感じなければ、欠損は生じない」

### Layer 1: 予測-誤差ループ

**機能**: ズレ検出、欠損生成（選別）

見立て（予測）と入力の照合によりズレを検出する。ズレの多くは前意識的に吸収されるが、一部は選別を通過して「欠損」として立ち上がる。

参照枠としては、予測符号化・自由エネルギー原理、精度（注意による重要度の調整）などの語彙で説明されることがある。ただし、これらは本モデルの主張を置き換えるものではない。

**関連概念**:
- Friston: 予測符号化、自由エネルギー原理（参照枠）
- 五蘊の「想」
- ヘーゲルの「知覚」

**D2との関係**: 欠損はここで立ち上がる


### Layer 2: 生存-信頼評価

**機能**: 価値判断（情動価の付与）

欠損（または欠損へ至るズレ）を生存軸（脅威）と信頼軸（愛着）で評価し、情動価を与える。これにより、行動準備が方向づけられる。

**関連概念**:
- Barrett: 構成主義的情動理論
- 五蘊の「行」
- 万川集海「正心」

**D4との関係**: 情動の構成（生存-信頼評価）はここで行われる

### Layer 3: 抱持

**機能**: 行動制御（保持）

評価済みの行動準備を即座に実行せず、保持し、再評価を可能にする。

**関連概念**:
- Bion: Container
- 世阿弥: 秘すれば花
- 葉隠: 忍ぶ恋

**D3との関係**: 抱持の定義そのもの

## 意のゲート

Layer 2とLayer 3の間に位置する概念的境界。

**統合表現**:
> 意のゲートとは、未発の中に留まり、誠に照らし、花を秘す境界である

**群盲象チェック**:
- 日本（芸道）: 秘すれば花
- 日本（武士道）: 忍ぶ恋
- 日本（忍術）: 正心
- 中国（儒教）: 未発の中、誠
- ドイツ（観念論）: 自己意識
