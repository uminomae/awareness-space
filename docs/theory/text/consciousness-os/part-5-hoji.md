本文書は4層モデルの最上位層（Layer 3: 抱持）を扱う。Layer 2（生存-信頼評価）から送られた行動準備を、即座に実行するか、保持するか、抑制するかを制御する。この層は意識的アクセスが可能であり、欠損駆動思考における「衝動と行動の間の空間」を提供する。

## 5.1 Layer 3の役割：行動を制御する

### 5.1.1 なぜ抱持が必要か

**[M]** Layer 2（生存-信頼評価）は、ズレに情動的価値を与え、行動準備を生成する。しかし、すべての行動準備が即座に実行されるべきではない。

**具体例**：
- 上司に怒りを感じた → 即座に怒鳴ると職を失う
- 魅力的な食べ物を見た → 即座に食べるとダイエットが崩れる
- 危険を感じた → 即座に逃げると状況を悪化させることがある

**[M]** Layer 3の役割は、行動準備を**保持**し、より適切なタイミングや方法を選択することである。これが「衝動の奴隷にならない」ための機構である。

### 5.1.2 抱持の定義

**[S]** **抱持（保持）**とは、評価済みの行動準備を、即座に実行せず一時的に保持する認知機能である。

**単純な反応抑制との違い**：

| 概念 | 内容 |
|------|------|
| 反応抑制 | 行動を**止める** |
| 抱持 | 行動を**保持しつつ再評価を可能にする** |

**[M]** 抱持は単に「やらない」のではなく、「待ちながら考える」ことを可能にする。

## 5.2 抱持の神経基盤 [P]

### 5.2.1 前頭前野の役割

**[P]** 反応抑制の中心的神経基盤は**前頭前野**である（Aron, 2007）。特に以下の領域が関与する：

| 領域 | 略称 | 機能 |
|------|------|------|
| 背外側前頭前野 | dlPFC | ワーキングメモリ、計画、意図の維持 |
| 前帯状皮質 | ACC | 葛藤検出、エラーモニタリング |
| 右下前頭回 | rIFG | 反応抑制の直接的実行 |

**[P]** Diamond (2013) は、反応抑制を実行機能の中核要素として位置づけた。実行機能は、目標指向的な行動を可能にする認知プロセスの集合である。

### 5.2.2 時間スケール

**[P]** Layer 3の処理は、Layer 0-2より遅い：

| Layer | 時間スケール | 特徴 |
|-------|-------------|------|
| Layer 0-1 | ミリ秒 | 自動的・連続的 |
| Layer 2 | 数百ミリ秒 | 高速だが評価を含む |
| Layer 3 | 秒単位 | 意図的・制御的 |

**[M]** この時間差が重要である。Layer 2で「怒り」が生成されても、Layer 3が介入する時間があれば、衝動的な行動を避けられる。

## 5.3 保持と解除の条件 [M+S]

### 5.3.1 抱持の開始条件

**[S]** 以下の条件で抱持が開始される：

1. **Layer 2で行動準備が生成された**
2. **即座の実行が不適切と判断された**
   - 社会的文脈（人前で怒鳴れない）
   - 長期目標との葛藤（ダイエット中）
   - 情報不足（状況をもっと知りたい）

### 5.3.2 抱持の終了条件

**[S]** 抱持は以下の形で終了する：

| 終了タイプ | 内容 | 例 |
|-----------|------|-----|
| **実行** | 状況が適切と判断し、行動を実行 | 安全な場所で感情を表現 |
| **キャンセル** | 行動準備自体が不要と判断 | 怒りが収まり、行動不要に |
| **再評価要求** | 状況変化、Layer 2へフィードバック | 新情報で評価が変わる |

### 5.3.3 抱持の失敗

**[M]** 抱持は常に成功するわけではない：

- **過負荷**: ストレス、疲労、認知負荷でLayer 3の機能が低下
- **強い情動**: Layer 2からの信号が強すぎてLayer 3をバイパス
- **習慣**: 自動化された行動はLayer 3を経由しない

**[P]** 前頭前野の機能は、ストレスホルモン（コルチゾール）により一時的に低下することが知られている。

### 5.3.4 抱持の質のスペクトラム（7段階） [M+S]

**[M]** 抱持（D3）は「する/しない」の二値ではなく、**保持の質にスペクトラム**がある（S26）。短期的には連続的だが、実務上は観測・設計のために段階として仮置きできる。

主軸（採用）: **問いとして保持できる時間 × 再評価可能性**  
補助軸: α機能/Container内在化、信頼軸の安全基地、実行機能（抑制/更新/切替）、生存軸過負荷耐性（自律神経・回復・代謝）など。

段階（概要のみ。詳細は `codex/archive/deepdive/REPORT-抱持-structuring.md` 参照）：

1. **非保持（凍結・解離）**：抱持が開始しない/維持できない  
2. **反射的解消（闘争・逃避・分裂）**：Layer 3をバイパスして即応で誤差を潰す  
3. **早期収束（即断・短絡）**：保留はできるが問いが閉じる（再評価が起きない）  
4. **擬似抱持（抑圧・回避・固着）**：保持に見えるが探索が起きず束に固着/スタック棄却  
5. **関係依存保持（共依存的抱持）**：二者系で「悪化しない」を実現する保持  
6. **good-enough 抱持（安全基地＋メタ認知）**：保持しつつ再評価し、解除を選べる  
7. **生成的抱持（集団/制度へ拡張）**：対話・制度・外部化により保持コストを分散し継続する

**[S]** この段階は「人格評価」ではなく、抱持が成立する条件（Layer 0〜3）の揃い方として扱う。同一人物でも疲労・関係・制度で上下しうる。

#### 観測の補助足場（運用語彙）

以下は「段階の確定」ではなく、観測・支援の識別力を上げるための補助足場である。

- 段階3（身体的兆候の運用語彙）:
  - 「腹側迷走が戻りつつ交感動員が残る（急かし）」として観測する（段階2との差分の言い方）。`[CONTEXT_DEPENDENT]`
  - 声量よりも、発話テンポ/間の短さ/呼吸の詰まりとして現れることがある。`[SPECULATIVE]`
  - 身体兆候だけでは段階3識別が弱い→L1/L3兆候と併用する。
- 段階4（更新の有無を見分ける補助観測）:
  - 語彙変化（同語反復か、言い換え・差分が出るか）
  - 質問応答パターン（問いが開くか、結論回収へ滑るか）
  - 外部化物の差分（メモ/図/チケット等が更新されているか）
  - 時間軸（停滞が「良い保留」か「同じ反復」かを、差分で追う）
- 段階5↔6（内在化/撤去タイミングの補助観測）:
  - 支援者不在の場面でも保持が継続する（不在時の保持）
  - 外部化が関係依存の代替足場として継続する（外部化の継続）
  - 別の関係でも保持・再評価・解除の運用が成立する（別関係での成立）
  - 撤去は「一気に外す」ではなく、介入を弱めつつ揺れの回復を観測して段階的に行う（断定ではなく原則）。

### 5.3.5 発達段階マッチング（S26仮説） [M+S]

**[M]** S26は「同じ発達段階 or 2段階離れた者同士で保持が成立し、隣接段階は衝突しやすい」というマッチング仮説を含む（中学1年と3年は仲が良いが2年は…）。

本稿では“法則”として断定せず、以下の作業仮説として扱う：

- 同段階：共鳴（保持コスト感・解除タイミングが近い）  
- 隣接段階：衝突（移行期の摩擦／保持の価値・速度・境界の置き方がズレる）  
- 2段階差：調和（師弟距離が生まれ、Containmentが成立しやすい）

**[S]** ただし「2」である根拠は現時点で薄い可能性があるため、裏付けが弱い箇所は `[SPECULATIVE]` として保持する。非対称性（師→弟のContainment）は本仮説の中核であり、詳細（有向7×7表）は `codex/archive/deepdive/REPORT-抱持-structuring.md` に委譲する。

## 5.4 欠損駆動思考と抱持 [S]

### 5.4.1 欠損の保持

**[S]** 欠損駆動思考において、抱持は決定的に重要である：

```
Layer 1: ズレ →「何かが欠けている」（欠損）
Layer 2: 生存-信頼評価 →「これは問題だ」（情動的価値）
Layer 3: 抱持 →「すぐに解決せず、問いとして保持する」
```

**[M]** 通常、欠損は「不快」であり、即座に解消したくなる。しかし、抱持により欠損を**問いとして保持**することで、より深い探索と創造的解決が可能になる。

### 5.4.2 欠損駆動ループとの接続

**[S]** 4層モデルは、欠損駆動ループの前半部分に対応する：

| 欠損駆動ループ | 4層モデル |
|---------------|----------|
| 誤差の感知 | Layer 0-1 |
| 欠損ログ化（5類型） | Layer 1-2 |
| 抱持（保持） | Layer 3 |
| 最小検証・再評価 | Layer 3 → Layer 2 フィードバック |

**[S]** 抱持の後、欠損は「創造5段階」（場→波→縁→渦→束）へと渡される。これはPhase 2（スピノル展開）で詳述されている。

### 5.4.3 検証可能な予測

**[S]** この仮説から導かれる予測：

1. **抱持能力と創造性**: 反応抑制能力が高い個人は、欠損を問いとして保持しやすく、創造的解決を生みやすい

2. **抱持能力と衝動性**: 反応抑制能力が低い個人は、欠損を即座に解消しようとし、衝動的な解決に走りやすい

3. **ストレスと抱持**: ストレス下では抱持能力が低下し、欠損駆動思考が困難になる

### 5.4.4 共依存の再記述（注意付き） `[非常識]` [M+S]

**[非常識]** ここでの共依存の記述は、一般的な「病理としての共依存」を否定したいのではなく、S26の仮説（共依存＝その段階で可能な最善の抱持）を**機能として**再記述する試みである。

- **[M]** 共依存的抱持（上のスペクトラム段階5）は、個体内の抱持が弱い状況で、二者関係（外的Container）により「それ以上悪化しない」保持を成立させる形として読める。  
- **[M]** これは「良い保持」と同一ではないが、段階1-2（凍結/反射処理）への急落を回避する“最低限の保持”として機能しうる。

**倫理的注意**: ここでの再記述は、共依存を推奨・肯定する意図ではない。あくまで「その段階で可能な保持として機能する」可能性を述べる。詳細は `codex/archive/deepdive/REPORT-抱持-structuring.md` を参照。

## 5.5 Phase 3 まとめと展望

### 5.5.1 4層モデルの統合

**[S]** Phase 3では、「意」の作動構造を4層モデルとして提示した：

| Layer | 名称 | 機能 | 神経基盤 |
|-------|------|------|---------|
| 0 | 内受容感覚 | 身体モニタリング | 島皮質 |
| 1 | 予測-誤差ループ | ズレ検出、欠損生成 | 皮質階層 |
| 2 | 生存-信頼評価 | 価値判断、情動生成 | 扁桃体、vmPFC |
| 3 | 抱持 | 行動制御、保持 | dlPFC、ACC |

**[M]** この4層が協働することで：
- 身体状態と外界が常時モニタリングされ（Layer 0-1）
- ズレが「欠損」として意識され（Layer 1-2）
- 情動的価値が付与され（Layer 2）
- 衝動的反応ではなく、創造的応答が可能になる（Layer 3）

### 5.5.2 Phase 4への展望

**[S]** Phase 4（臨床・発達心理学との統合）では、以下を扱う予定：

1. **愛着と信頼軸**: 愛着パターン（安定型、回避型、不安型）と信頼軸評価の関係
2. **発達と抱持**: 実行機能の発達に伴う抱持能力の成熟
3. **臨床とLayer機能**: 各種精神疾患における4層の機能不全
4. **心理療法と欠損**: 欠損の扱い方、抱持訓練
5. **外発的動機と抱持（ISS-32）**: 動機づけが保持の質（早期収束/擬似抱持など）に与える影響
6. **フロー中の抱持状態（ISS-33）**: フローが抱持の“変形”なのか、別の状態なのかの定義
7. **集団抱持/組織的抱持（ISS-34）**: 対話・制度・外部化による保持の設計と、その失敗パターン
