## 本文書の位置づけ

本文書は4層モデルのLayer 1（予測-誤差ループ）を扱う。Layer 0（内受容感覚）からの身体状態表象と、外受容感覚からの入力を照合し、ズレ（違和感）を検出する。このズレの大部分は前意識的に吸収されるが、一部は「欠損（Kesson）」として意識に立ち上がり、Layer 2（生存-信頼評価）へ渡される。

以降、便宜的にこの「入力と見立ての差」を総称して「ズレ」と呼ぶ。参照枠では「誤差」、体験語彙では「違和感」とも言い換える。

本稿で扱う「予測-誤差」「精度」「注意」などの語彙は、**発想の起点であり、類似性を示す参照枠**である。主語は「欠損」という一人称的現象と、それが問いとして保持されるプロセスに置く。

**レイヤ分離**：
- **[P]** Physics/Physiology: 実験的事実・観察可能な相関物
- **[M]** Metaphor: 発想の起点となる比喩・解釈・図式
- **[S]** Speculation: 検証可能な仮説

## 3.1 Layer 1の役割：ズレを検出し、欠損の芽を選別する [M+S]

### 3.1.1 入力と出力

**[M]** Layer 1は、次の入力を受け取る：
- **Layer 0から**：身体状態表象（内受容）
- **外界から**：外受容入力（視覚、聴覚など）

**[M]** Layer 1が行うのは、入力を「そのまま受け取る」ことではなく、入力が“こうであるはず”という見立てと照合し、ズレを検出することである。このズレは、まだ価値判断（良い・悪い）を含まない。

**[S]** Layer 1の出力は二段階に分かれる：
1. **前意識的に吸収されるズレ**（多くはここで消える）
2. **選別されるズレ**（欠損の芽としてLayer 2へ渡る）

### 3.1.2 「予測-誤差ループ」という名称について

**[M]** 本プロジェクトはLayer 1を「予測-誤差ループ」と呼ぶが、ここで重要なのは特定理論への帰属ではなく、次の機能的要件である：
- 期待（見立て／予測）と入力の照合がある
- 照合の結果としてズレが生じうる
- ズレの多くは棄却され、一部だけが次層へ送られる

---

## 3.2 欠損：誤差が「欠け」として経験される [M+S]

### 3.2.1 ズレの“現象”としての顔

**[M]** ズレは単なる「違い」「ズレ」ではなく、しばしば **「ないこと」「欠けていること」**として経験される。

**具体例1：期待外れの味**
- コーヒーと思って飲んだら紅茶だった
- 「コーヒーの味が**ない**」という感覚
- 期待していた苦味、香りが「**欠けている**」

**具体例2：会話の違和感**
- いつもの友人が、妙に素っ気ない
- 期待していた温かさ、親しみが「**ない**」
- 「何かが**足りない**」という感覚

**具体例3：パズルの未完成**
- ジグソーパズルのピースが一つ足りない
- 完成形の見立てがあるからこそ、欠けが際立つ

### 3.2.2 「欠損」という概念

**[M]** 「欠損（Kesson）」とは、ズレが意識において「欠け」として立ち現れ、**問い**を生成する主観的経験である。

**特徴1：否定性**
- 欠損は「何かが**ない**」という否定的経験
- 「あるべきもの」の見立てが先行しているために生じる

**特徴2：問いの構造**
- 欠損は「何が欠けているのか？」という問いとして立ち現れる
- この問いが、探索と学習を駆動する

**特徴3：情動価への接続**
- 欠損は通常、何らかの“気になる・困る・惹かれる”を伴う
- その方向づけ（脅威か、愛着か、機会か等）がLayer 2で明確化される

**[S]** 欠損は、ズレの“一人称的な顔”である。ただし、すべてのズレが欠損になるわけではない（次節）。

### 3.2.3 欠損の5類型（暫定）

**[S]** ズレがどの側面で生じたかによる分類：

| 類型 | 定義 | 例 |
|------|------|-----|
| **観測欠損** | 感覚レベルのズレ | 予期していた音が聞こえない |
| **主体欠損** | 自己の見立てのズレ | 「自分が自分でない感じ」 |
| **正当化欠損** | 因果・理由のズレ | 「なぜ怒っているのか分からない」 |
| **一貫性欠損** | 記憶・物語のズレ | 「つじつまが合わない」 |
| **意味欠損** | 意味・概念のズレ | 「これは何だ？」 |

## 3.3 どのズレが欠損になるか：選別条件 [P+M+S]

### 3.3.1 前意識的処理と「浮上」

**[P+M]** まず重要な事実を確認する。すべてのズレが意識に上るわけではない。むしろ大部分の照合処理は意識の外で行われ、更新・補正・棄却として吸収される。

**[S]** ここで本モデルが主張するのは次である：
- Layer 1には、**ズレを“次層に送るかどうか”の選別**がある
- この選別が、欠損（問いの芽）の密度を決める

### 3.3.2 選別の鍵としての「精度」概念（参照枠）

**[M]** 参照枠として、予測符号化の語彙で言えば、意識に上りやすいズレは「精度（重要度・信頼度）が高い」ズレである、と言い換えられる。

**[S]** 本プロジェクトでの操作的な読み替え：
- **精度が高い**＝「放置できない」「気になる」「対応が要るかもしれない」と感じるズレ
- **精度が低い**＝「更新で吸収される」「無視できる」ズレ

**注意**：ここでの「精度」は参照枠の用語を粗く借りた操作的表現であり、厳密な数学的定義（例：分散の逆数）を本稿で与える意図はない。

### 3.3.3 注意と意識の関係（参照枠の要約）

**[P]** 注意（attention）は、参照枠としては「精度の調整」として理解できる、とされることがある。

**[M]** 本稿の目的に必要なのは、次の最小点である：
- 注意は、ズレの“目立ちやすさ”を変える
- 目立ったズレが、欠損として立ち上がりやすい

## 3.4 参照枠（要約）：予測符号化・自由エネルギー・階層推論 [P+M]

この節は、Layer 1を「予測-誤差ループ」と呼ぶ際の参照枠を、必要最小限で要約する。

### 3.4.1 予測符号化（最小要約）

**[P]** 参照枠としての要点：
1. 脳は入力に対する見立て（予測）を持つ
2. 入力と見立ての差がズレとして計算されうる
3. ズレは、更新（学習）または行動によって小さくされうる

### 3.4.2 自由エネルギー原理（最小要約）

**[P]** 参照枠としての要点：
- 生物システムは、驚き・不確実性を小さくする方向に振る舞う、とされる
- その実装として、見立ての更新（知覚的推論）と行動（能動的推論）が区別される

### 3.4.3 「制御された幻覚」について（位置づけ）

**[M]** 「知覚は制御された幻覚である」という表現は、知覚が“入力そのもの”ではなく、見立てと入力の相互作用で成立するという直感を与える。ここでは比喩として参照するに留め、これが欠損の説明を尽くすとは主張しない。

## 3.5 本論を指し示す別の現象：睡眠夢と予測-誤差ループ [P+M]

### 3.5.1 「意」の基本性：睡眠でも作動する

**[M]** Layer 1の照合とズレ検出は、覚醒時だけでなく睡眠夢でも作動していると捉えられる。これは、Layer 1が高次認知（思考・推論・記憶）とは独立した、より根源的なプロセスであることを示唆する。

**[P]** REM睡眠中、前頭前野（特に背外側前頭前野）の活動が低下することが報告されている一方で、夢の中で私たちは“違和感”“追跡”“欠け”を経験する。

### 3.5.2 夢における欠損（例）

**[M]** 夢の中で経験される欠損の例：
1. **運動の欠損**：逃げられない、走れない、叫べない
2. **論理の欠損**：矛盾に気づかない
3. **記憶の欠損**：覚醒時の記憶にアクセスできない
4. **不安と追跡**：「何かが足りない」「何かに追われる」

**[M]** ここで重要なのは、夢が“参照枠の正しさ”を証明することではなく、Layer 1が指し示す現象が複数の局面で観察される、という点である。

---

### 3.5.3 観察可能な相関物の候補（暫定）

**[P+M]** Layer 1が指し示す「ズレの検出」には、完全な同一視は避けつつも、観察可能な指標候補が存在する。ここでは「本論を指し示すための候補」を列挙し、確定や還元は行わない。

| 目的 | 指標候補（例） | 解釈上の注意 |
|---|---|---|
| 予期違反の検出 | 予測誤差関連電位（例：MMN）、驚愕反応 | 相関物であり、欠損そのものの測定ではない |
| 注意・重要度の変化 | 瞳孔径、皮膚電気反応など | 「精度」概念の厳密な測定とは別物 |
| 更新・吸収の様式 | 反復抑制など | 反応減衰＝“欠損がない”とは限らない |

## 3.6 類似点と相違点：本モデルと参照枠の関係 [S]

**[S]** 本モデル（欠損駆動思考）は、参照枠（予測符号化等）と構造的な類似性を持つが、同一視しない。

| 観点 | 参照枠（予測-誤差等） | 本モデル（欠損駆動思考） |
|---|---|---|
| 主語 | 三人称の計算・推論の説明 | 一人称の欠損（否定性）と問い |
| 中心概念 | 誤差最小化、更新、行動 | 欠損の保持（抱持）と創造への接続 |
| 誤差の扱い | 原則として縮減される対象 | 一部は保持され、探索を駆動する対象 |
| 役割 | 参照枠（鏡） | 本論（処理系の記述） |

## 3.7 Layer 1からLayer 2へ：インターフェース [M+S]

**[M]** Layer 1で検出されたズレのうち、**選別を通過したもの**がLayer 2（生存-信頼評価）へ送られる。

### 送られるもの

| 項目 | 内容 |
|------|------|
| ズレ | 何がどれだけ見立てと異なるか |
| 重要度の手掛かり | 「気になる」「放置できない」等の目立ち（参照枠では精度） |
| 文脈情報 | どの領域・状況で生じたズレか |

### 送られる条件（暫定）

**[S]** 以下の条件を満たすズレがLayer 2へ送られる：
1. **目立つ**：重要度が高い（注意が向いている／生活上の意味が大きい）
2. **自動更新で解決しない**：前意識的処理で吸収できない
3. **行動関連性がある**：何らかの対応を要する可能性がある

### Layer 2での処理（予告）

**[M]** Layer 2（生存-信頼評価）では、送られてきたズレに対して：
- **生存軸**：生存・脅威の観点から評価
- **信頼軸**：愛着・所属の観点から評価

この評価により、ズレは情動価を帯び、行動準備が生成される（詳細はPart 4）。

## Part 3 まとめ

**[S]** Layer 1（予測-誤差ループ）は、欠損の“入口”である：
1. **入力**: Layer 0（内受容）+ 外受容入力
2. **処理**: 照合とズレ検出（多くは前意識的に吸収）
3. **出力**: 選別されたズレが欠損として立ち上がり、Layer 2へ送られる

**[S]** 参照枠（予測符号化等）は、Layer 1を理解するための鏡であり、本論の代替ではない。

次のPart 4では、Layer 2（生存-信頼評価）がズレに価値を与え、情動と行動準備を生成する仕方を扱う。
