# awareness designer — 生成ルール v1.0

**タイトル**: 意識モデルを観察の道具として使う  
**読者**: 教育者・対人支援者・チーム設計者  
**文書類型**: モデル解説 / 構造案内  
**文体**: です・ます調。「一緒に見てみましょう」のトーン  
**文字数**: 4,000〜6,000字

## 構成

生成物の見出しは一般的な見出しを使う。
ルール内の区分名をそのまま見出しにしない。

1. **この guide が何であり何でないか**
   - 現場で人の反応を観察するためのモデル解説であることを明示する
   - 実践マニュアルや診断ラベルではないことを最初に置く
   - 完成理論ではなく、調査結果を踏まえた現時点の構造仮説だと明示する
   - guide 自体は summary であり、詳細な論拠は report / survey / design memo にあることを明示する

2. **モデルの中心仮説**
   - 4層モデルを観察フレームとして提示する
   - F-O軸を「何を守ろうとしているか / 何との関係を保とうとしているか」を読む仮説座標系として説明する
   - `Withhold` は必要な場合のみ、応答を固定化しない余地として扱う

3. **その仮説を支える調査**
   - 神経現象学と心理学を中心参照にしていること
   - 発達心理学、愛着、間主観性、信頼が O軸側の主要調査論点であること
   - M1 と Concept Notes が source 束として参照されていること
   - reader-facing report がまだ無い論点は、調査中または設計段階であることを明示する

4. **現場で何が見えるか**
   - 教育、支援、チームの少なくとも3場面で観察サインを書く
   - 各場面で Layer 0-3 と F/O の読みがどう違いを生むかを書く
   - よくある見誤りも併記する

5. **どこまで進んでいるか**
   - source は蓄積されているが、統合理論としての整理は途中であることを書く
   - report は構成要素ごとの公開ドラフトであり、全体統合はまだ未完であることを明示する
   - 現場への応用可能性はあるが、まだ検証しきれていないことを書く

6. **何がまだ未解決か**
   - F-O軸の境界
   - 神経現象学と心理学の役割分担
   - 観測可能性
   - `Withhold` の位置づけ
   を、実践現場での限界として読めるように書く

7. **次の入口**
   - survey への導線
   - general / academic 版への導線
   - 構成要素 report への導線
   - report が未整備の論点については、design memo や survey を案内する

## 注意

- 方法論の押し売りにしない
- 「正しい反応」や「成熟した反応」を規定しない
- `欠損駆動思考`, `Kesson`, `D1-D4`, `kesson-driven-thinking` を本文に出さない
- F-O軸を確定診断軸として扱わない
- 実践上の有用性と理論的確定を混同しない
- report のない主張を、現場で使える確定知として書かない
