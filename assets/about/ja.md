# 意識とは

意識は頭の中だけで起きているのでしょうか。

この探索では、意識の作動構造を4層モデル（M1）で記述しています。

L0 内受容感覚 — 身体モニタリング。身体内部からの信号が意識の土台を形成します。
L1 予測-誤差ループ — ズレ検出、欠損生成。脳の予測と現実のずれが気づきを駆動します。
L2 生存-信頼評価 — 価値判断（情動価の付与）。生存・愛着軸による意味づけです。
L3 抱持 — 行動制御（保持）。即座に行動せず保持することで、より深い探索を可能にします。

間主観性は M1 の外にある探索テーマとして別途扱っています。

AIとの協働で構造化を進めています。まだ途上にあります。
